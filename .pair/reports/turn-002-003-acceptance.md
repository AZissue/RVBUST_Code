## 4. 实现要点（读 diff 后确认）

- `ToolsPanel::updateOfflineFreeze()` 是唯一的冻结判据：面板可见 + 当前堆叠页 == 像素→3D +
  离线 + 目录/图像有效；五个状态入口（`showEvent` / `hideEvent` / `onToolChanged` /
  `applyPixelTo3DMode` / `refreshPixelTo3DImages`）全部汇到它。
- `Image2DView::setFrozenImage/clearFrozenImage/frozen`：冻结期间 `updateFrame()` 仍保存
  最后一张真实帧，解冻时用它恢复；没有真实帧就清空画面（未连相机时表现为黑屏，符合预期）。
- `MainWindow` 里 `pixelClicked` → 既有 `on2dPixelPicked`（黄球/卡片/提示）未改，
  额外在「面板可见 + 离线」时转发给工具页。
