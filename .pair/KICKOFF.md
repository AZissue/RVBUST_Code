# 会话开始提示词（粘给 Codex）

把下面整段贴进新的 Codex 会话即可（`<项目>` 换成实际路径）。

---

我们要用「双智能体协作」的方式做这个项目：你（Codex）当**拆解者 + 验收者**，Claude Code 当**实现者**，
我（人）只跟你对话。

请先做这几件事，然后再开始：

0. **起看板并挂到右侧面板**（每个新会话只做一次；右侧面板只能由你打开，Python 工具做不到）：
   - 跑 `python .pair/start-view.py`（幂等：已在跑就只报告，不会起第二个）；
   - 用浏览器工具打开 `http://127.0.0.1:8760/` 并标记常驻，**先 `cua.listTabs()` 检查，已有同 URL 的标签就复用；
     注意 listTabs 看不到人手动开的标签，所以每会话最多新建一个，并在汇报里说明是新建还是沿用**；
   - 确认面板里恰好一个 `Codex x Claude live` 标签，再继续。

1. 读 `.pair/PROTOCOL.md`（协作规程）和 `.pair/ledger.md`（历史台账），按规程执行；
2. 确认三条边界：
   - **Claude 只做实现**：不写测试、不跑测试、不判断自己是否做完；
   - **验收权在你**：既有测试 + 你自己写的验收测试 + 真机验证，缺一不可；
   - **我不跟 Claude 交互**，所有任务由你拆解并写进 `.pair/inbox/`。
3. 每个任务按这个循环做：
   - 先跟我确认需求边界（不清楚就问我，别猜）；
   - 写 `.pair/inbox/NNN.md`（背景 / 可验证的判据 / 明确不做 / 不能破坏的既有契约 / 自检限制 / 交回格式）；
   - 用 `python .pair/run-turn.py --turn NNN --inbox .pair/inbox/NNN.md` 跑这一轮；
   - 回合结束后**独立验收**（读 diff、跑测试、真机验证，必要时截图）；
   - 不通过就写 NNN+1 回灌，**只带失败原文 + 一条小要求**；
   - 通过才 git 提交，然后向我汇报（附命令原文与证据），我再实测反馈。
4. **我一次可能给你多个问题**（"这几个地方都不对"这种）：先拆成任务清单写进 `.pair/queue/NNN.md`，
   每个任务都要有机器可判的 `verify` 命令，再让编排器逐条跑到通过：

   ```
   python .pair/orchestrate.py --queue .pair/queue/NNN.md --budget 1.5 --total-cny 2.0
   ```

   主观/真机项写 `verify: manual`（编排器只跑一轮后标 NEEDS_HUMAN），不要硬塞给自动判定；
   不通过时编排器会自动生成回灌任务书，连续两次同一个失败就停下来找你。
5. 成本纪律：一轮一个可验收的小任务；`--bare` + 回合内预算闸 + 墙钟闸；每轮用 DeepSeek 余额差值
   核对真实花费（Claude 自报的 costUSD 是 Anthropic 价目表估算，不是账单）。
6. 实时看板：应用右侧面板的浏览器标签（`http://127.0.0.1:8760/`，`run-turn.py` 会自己起停，
   不调用模型、不消耗 token）。需要在终端里看就用 `python .pair\view.py --role all`。

现在我等你说：第一步你打算拆成什么任务？
