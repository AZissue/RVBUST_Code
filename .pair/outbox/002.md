## 4. 逐条对照判据

1. **编译满足，ctest 未跑（不确定）**：`cmake --build build --config Release` 退出码 0（输出见上）。
   `ctest` 按限制未执行，24 类 / 270 passed 是否保持无法自证，需 Codex 复核（本轮未动 `tests/`）。
2. **满足**：`ToolsPanel.{h,cpp}` 中 `m_p2dView`、`new Image2DView`、`ui/Image2DView.h` 的 grep 均为空。
3. **满足**：控件 objectName = `p2d_mode`；两项文案含「离线」「在线」；`setCurrentIndex(0)` 默认离线；
   `applyPixelTo3DMode()` 在切换时立即 `setEnabled(!online)`（数据文件夹整行容器 + 图像下拉 +
   内参 + 外参，连标签一起禁用），在线时 `p2d_hint` 给出「在线模式：相机取点链路尚未提供…」提示；
   离线时 `p2d_pixel` 保持可用。
4. **满足**：三个方法签名与任务书一致（`frozen()` inline，其余在 .cpp 实现）。
5. **满足**：信号与槽签名照抄（见第 2 节）。
6. **满足**：`pixelTo3DOfflineImageRequested` → `m_view2d->setFrozenImage(img)`（null 时 log error +
   toast「无法加载离线图像：xxx」）；`pixelTo3DOfflineImageEnded` → `clearFrozenImage()`；
   `pixelClicked` 先走既有 `on2dPixelPicked`，再在离线模式转发；
   `hideEvent` 与切到在线都发 `pixelTo3DOfflineImageEnded()`（另有 `showEvent` 打开工具时重新冻结）。
7. **满足**：`m_p2dDir` 的 `textChanged` → `refreshPixelTo3DImages()`；目录为空/无 png 时
   `p2d_hint` = 「该目录下没有 png 图像」并解冻（不崩溃）。

## 5. 不确定点 / 发现但没做的事

- **ctest 没跑**（判据 1 后半），也没有启动 GUI 做人工验证；判据 3/6/7 的行为只做了代码级确认。
- **点击转发的可见性条件**：MainWindow 只在 `m_toolsPanel->isVisible()` 时才转发离线点击。
  理由：⑤ 说的是「工具打开期间」，且工具页隐藏时不应再改它的输入框。若 Codex 期望「只要模式是离线
  就转发」，去掉这个 `isVisible()` 判断即可（一行）。
- **冻结时切页**：`refreshPagePixmap()` 在冻结期间对所有页都返回冻结图，所以离线期间用户点
  「偏差图/截面轮廓…」看到的仍是那张 png；解冻后自动回到真实帧。没做「冻结时禁用页面栏」。
- **`clear()` 与冻结的交互**：若相机断开时调用 `m_view2d->clear()`，UI 空白但 `m_frozen` 仍为 true，
  要等工具页隐藏/切在线才解冻回实时。未处理（不在判据内）。
- **`showPixelTo3DImage()` 的语义变了**：现在只发信号、不再自己加载图（图由 MainWindow 加载并冻结）。
  「浏览」按钮仍会 `setText` 后再显式 `refreshPixelTo3DImages()`，与新增的 `textChanged` 触发重复刷一次，
  功能无差别（会多发一次 request/ended），未删除这行以免动到既有逻辑。
- **在线模式**下点主 2D 视窗不出结果：按「明确不做」，MainWindow 的转发被 `pixelTo3DOffline()`
  挡掉；在线模式的取点链路留给 003。

  要求的情况下动它。
