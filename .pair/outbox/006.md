## 2. 两个新风格函数的完整 QSS

```cpp
QString viewOverlayLabelStyle()
{
    return QStringLiteral(R"(
        QLabel {
            color: #FFFFFF;
            background-color: rgba(0, 0, 0, 0.20);
            border: none;
            border-radius: 4px;
            padding: 3px 8px;
            font-size: %1px;
        }
    )")
    .arg(FONT_HINT);
}

QString viewOverlayButtonStyle()
{
    return QStringLiteral(R"(
        QPushButton {
            color: #E6EAF2;
            background-color: rgba(0, 0, 0, 0.20);
            border: none;
            border-radius: 4px;
            padding: 3px 9px;
            font-size: %1px;
        }
        QPushButton:hover { background-color: rgba(0, 0, 0, 0.28); }
        QPushButton:pressed { background-color: rgba(22, 119, 255, 0.30); }
        QPushButton:checked {
            background-color: rgba(22, 119, 255, 0.30);
            color: #FFFFFF;
            font-weight: 600;
        }
        QPushButton:disabled { color: #9AA0AA; background-color: rgba(0, 0, 0, 0.12); }
    )")
    .arg(FONT_HINT);
}
```

- 两条都含 `border: none` 与 `background-color: rgba(`；
- 出现的 alpha 只有 `0.20 / 0.28 / 0.30 / 0.30 / 0.12`，**最大 0.30**，没有超过 0.30 的；
- 按钮样式带 `:hover` 与 `:pressed` 两态（另外保留了 `:checked` 与 `:disabled`，
  前者是页面栏/开关按钮的选中态，后者是「清除 ROI」无 ROI 时的禁用态——两态原来就有）。

## 4. 不确定点

- **`VisSceneView::m_pickHint` 没换样式**（`识别后可点击场景中的点选择填充`，现为
  `color:#1677FF; background: rgba(0,0,0,0.5)`）。判据 3 只点名了「工具栏按钮 + 占位文字标签」，
  这个标签两者都不是（是识别后的临时提示、默认隐藏），所以我按范围没动它。
  如果你认为"3D 视窗里的所有文字标签"都要统一，把它那行换成
  `Theme::viewOverlayLabelStyle()` 即可（它在 `VisSceneView.cpp` 约 605 行）。
- **`HoverTipLabel`（`src/ui/VisSceneView.cpp` 顶部匿名命名空间的悬浮提示类）没动**：它自己重写
  `paintEvent()` 画"白字 + 黑描边"、背景本来就是全透明（`background: transparent; border: none;`），
  给它套半透明底反而会盖住自绘的文字阴影，且它不在判据 3 的名单里。
- **3D 三个按钮的内边距由 `4px 12px` 变成 `3px 9px`**（新函数与 2D 页面栏共用一套 padding，
  签名无参数、只能取一个值；取小的那个是为了不让 2D 页面栏变宽）。按钮因此各小约 1px/3px，
  属"视觉"范畴、不影响布局与点击；若要求 3D 保持原 padding，需要给函数加参数或在其后追加一条 rule。
- **`:checked` 从实心蓝 `#1677FF` 变成 `rgba(22,119,255,0.30)`**：这是"无实心底色"的直接后果。
  选中页/开关仍然可辨认（蓝底 + 白色加粗字），但对比度比原来弱。判据 5 的"状态仍会切换"
  由仍存在的 `:checked` 规则保证。
- **标题加粗与占位字号用"追加一条 rule"的方式保留**（`Theme::viewOverlayLabelStyle() + "QLabel { … }"`），
  所以这两处的 `setStyleSheet` 不是纯函数调用；如果 Codex 用"必须只调用该函数"来核对，需要放宽。
- 只做了代码级确认：真机截图与新样式是否"淡到看得见底下的图像"需要 Codex 看（判据 5）。
