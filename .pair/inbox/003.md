# 003 —（回灌）冻结必须跟「像素→3D 页」绑定

## 失败原文（Codex 真机复现，不是推断）

上一轮（002）的离线冻结做对了"打开工具就显示离线图"和"关掉工具就还原"，但**冻结没有跟当前工具页绑定**。
真机步骤与观测（主 2D 视窗中心区域平均亮度：实时图 = `0.00`，冻结的离线图 ≈ `35.7`）：

```text
1) 工具窗停在「欧氏距离」页，主 2D 视窗 = 0.00（正常）
2) 关掉工具窗（点面板自己的「关闭」）        → 主 2D 视窗 = 0.00（对）
3) 重新打开工具窗（当前工具页仍是「欧氏距离」）→ 主 2D 视窗 = 35.73（**错**：主视窗被离线图冻住了，
   而此时用户根本没在用像素→3D 页）
4) 在工具窗里从「像素→3D」切到「欧氏距离」      → 主 2D 视窗仍是 35.73（**错**：切走了也没解冻）
```

证据文件：`.pair/reports/002-reopen-on-other-page.png`（步骤 3 的画面，面板停在欧氏距离、
主 2D 却显示离线图）、`.pair/reports/002-real-close.png`（步骤 2 的对照画面，主 2D 是黑的）。

## 这一次只要求一件事

**把"冻结"的生效条件收敛为下面三条同时满足，任一不满足就立刻 `clearFrozenImage()`：**

1. 工具面板可见（`isVisible()`）；
2. 工具列表当前页是**像素→3D**（不是"面板被打开"）；
3. 模式是**离线**且数据文件夹/图像有效。

需要覆盖的状态转换（这就是验收判据）：

- 打开面板但当前页不是像素→3D → **不冻结**（这条现在就是错的）；
- 在面板里从像素→3D 切到别的工具页 → **立刻解冻**；
- 在面板里从别的工具页切回像素→3D（离线、目录有效）→ 重新冻结；
- 关掉面板 → 解冻（这条已经对了，别弄坏）；
- 模式切到在线 → 解冻（这条也已经对了，别弄坏）。
