# 004 — 像素→3D「在线」取点：主 2D 左键 → 主 3D 显示 → 工具页结果可复制

## 背景

离线链路已经验收通过（主 2D 视窗显示所加载文件、点击回填工具页、数值与真值一致）。
本轮补用户反馈 6-④ 的**在线**部分：连接相机并拍照之后，在主 2D 视窗左键点像素 →
主 3D 视窗显示对应的 3D 点（与识别同心圆圆心那套显示一致）→ 工具页结果行可复制。

现状：`MainWindow::on2dPixelPicked()` 已经有"点击取点 → 3D 黄球 + 填相机目标点卡片 + 提示 + 日志"，
但它**直接调用 `PixelTo3DTools`**，且没有喂给工具页。本轮把它改成走共享服务，
并在「工具面板可见 + 当前页是像素→3D + 模式为在线」时把结果推给工具页。

## 判据（逐条可验证）

1. `cmake --build build --config Release` 退出码 0；`ctest` 仍然 2/2 通过；
   `unit_tests` 不低于 **24 类 / 270 passed**（不得改 `tests/`）。
2. `MainWindow::on2dPixelPicked()` 不再直接调用 `PixelTo3DTools::*`（改为构造
   `PixelTo3DService::Source` 再 `query()`）：`rg "PixelTo3DTools::" src/app/MainWindow.cpp` 无匹配。
   - 对齐帧：`xyzMm = grid`、`imageWidth/Height = gw/gh`、无对应图 → 走对齐直查；
   - 线扫未对齐帧：把 `m_camera->lastCorrespond()` 得到的对应图填进 `Source::correspondMap`
     （保留现有 `m_correspondBuilt` 缓存策略即可），`imageWidth/Height` 用对应图尺寸；
   - 两者都拿不到时给出与现在同义的中文提示，不要静默。
   - 既有副作用**全部保留**：3D 黄球、`camera_target_xyz` 卡片、侧栏提示、`m_logger->info` 日志。
3. 工具页新增（签名照抄）：

```cpp
signals:
    // 在线模式：请主窗口用当前采集帧执行一次像素→3D 查询
    void pixelTo3DOnlineQueryRequested(int pixelX, int pixelY);
public slots:
    // 主窗口的查询结果：ok=false 时 message 是可读中文原因
    void setOnlinePixelResult(int pixelX, int pixelY, bool ok,
                              double xMm, double yMm, double zMm,
                              const QString& message);
```

4. 在线模式下的工具页行为：
   - 主 2D 点击到达时（由 MainWindow 转发，沿用 002/003 的条件判断，把"离线"换成"在线"）
     → 结果行显示 `X.XXX, Y.YYY, Z.ZZZ`，「复制」按钮复制同一串；同时 hint 显示一行上下文
     （例如 `像素 (x, y) → 3D`），失败时 hint 显示 `message`；
   - 点「计算」→ 用手输的像素坐标发 `pixelTo3DOnlineQueryRequested`（同一链路，不另写一份计算）；
   - 在线模式下 `applyPixelTo3DMode()` 的提示不再是"尚未提供"，改为"在线：连接相机并拍照后，
     在主 2D 视窗左键取点"。
5. 主 3D 视窗显示该点，**复用既有识别标记那一套**：沿用 `VisSceneView::addSphere(...)`（现有取点用的黄色小球；
   新的一次取点先 `removeObject` 旧球，不要越积越多）；同时在主 2D 视窗上用
   `Image2DView::drawMarkers()` 留一个标记（与识别圆心标记同一套），新一次拍照/识别会按现有逻辑清掉。
6. **离线路径不许回归**：探针目录 + 像素 `5, 7` 仍必须得到 `453.125, 906.250, 1359.375`。

## 明确不做

- 不改 `logic/PixelTo3DService.*`（服务已验收，只许调用）
- 不改离线冻结逻辑（002/003 刚验收过）
- 不改识别（`DetectionEngine` / 同心圆）与测量页、机器人页、标定页
- 不改 `MainWindow::on2dPixelPicked` 的既有副作用（黄球/卡片/提示/日志）
- 不改 `tests/`、`codex_testData/`、`config/`

## 不能破坏的既有契约

- 工具页控件对象名不变（`p2d_mode`、`p2d_dir`、`p2d_image`、`p2d_intrinsic`、`p2d_extrinsic`、
  `p2d_pixel`、`p2d_result`、`p2d_hint`）；结果行格式仍是 `X.XXX, Y.YYY, Z.ZZZ`
- 未连接相机时点击主 2D 视窗，必须仍然给出「请先连接相机并拍照后再点击取点」这类提示
- `tests/` 归 Codex 独占

## 本轮允许的自检限制

- 不要跑 `ctest`、不要启动 GUI、不要拼接命令
