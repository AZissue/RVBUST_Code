# 006 — 2D/3D 视窗的标签与工具栏按钮：无边框 + 无底色（半透明背景）

## 背景

用户反馈 4（2026-09-20 细化）：**「2D 和 3D 视窗的标签和工具栏的按钮，是无底色」**，
原话是「无边框、无底色、半透明背景即可」。范围**只限这两个视窗**，不含设置页、工具面板、设备列表。

现状：`Image2DView` 的标题标签（`2D 实时图像`）、缩放标签（`适应`/百分比）和底部工具栏
（`图像 | 偏差图 | 尺寸总图 | 截面轮廓 | 重复性趋势 | 清除 ROI`）是**实心深色底**；
`VisSceneView` 的工具栏（`复位 | 叠加历史 | 偏差着色`）与占位文字同理。
要把它们统一成「没有边框、没有实心底色，只有一层很淡的半透明底」。

## 判据（逐条可验证）

1. `cmake --build build --config Release` 退出码 0；`ctest` 2/2 通过；
   `unit_tests` 不低于 **24 类 / 271 passed**（`tests/` 不许改）。
2. `src/ui/Theme.h`（+ 实现）新增两个风格函数，名字照抄：

```cpp
    // 2D/3D 视窗上的文字标签：无边框、无实心底色，只有一层很淡的半透明底。
    QString viewOverlayLabelStyle();
    // 2D/3D 视窗底部工具栏的按钮：同上，悬停/按下时略亮一点。
    QString viewOverlayButtonStyle();
```

   两者生成的样式表都必须同时包含 `border: none` 与 `background-color: rgba(`，
   且 alpha **不得超过 0.30**（即"淡"到看得见底下的图像）；按钮样式还要有 `:hover` / `:pressed` 两态。
3. `Image2DView` 里**这些**控件改用上述样式：标题标签、缩放标签、底部页面栏的全部按钮
   （含 `清除 ROI`）；`VisSceneView` 里：工具栏按钮（复位/叠加历史/偏差着色）与占位文字标签。
4. **行为与布局不许变**：控件文字、objectName、按钮顺序、工具栏位置、点击行为、页面切换、
   2D 缩放/平移、3D 交互一律保持原样（唯一变化是视觉）。
5. 真机（Codex 做）：截图对比 2D/3D 视窗；点一次 3D 的 `偏差着色` 与 2D 的 `偏差图`
   确认按钮仍然可点、状态仍会切换（不是被透明样式遮住或点不动）。

## 明确不做

- 不动测量页、工具面板、设置对话框、设备列表、顶部导航（用户明确只点了这两个视窗）
- 不改 `Theme.h` 里既有函数的行为（其它页面还在用）
- 不改任何布局尺寸/间距，不动 2D/3D 的绘制逻辑与数据链路
- 不改 `tests/`、`codex_testData/`、`config/`

## 不能破坏的既有契约

- 既有 `unit_tests` 全绿、数量不降；`tests/` 一个字符都不要动
- 2D 视窗工具栏按钮的 objectName / 文本不变（`清除 ROI` 等按现有实现保留）
- 3D 视窗的 `复位` / `叠加历史` / `偏差着色` 三个按钮文本与顺序不变

- 不要跑 `ctest`、不要启动 GUI、不要拼接命令
