# 002 — 像素→3D：加「在线/离线」开关，离线改由**主 2D 视窗**取点

## 背景

`像素→3D` 工具页现在自带一个内嵌 `Image2DView`（`m_p2dView`）：它显示加载的 png、
点一下取一个像素。用户要求（反馈 6-①③⑤）：

- **①** 删掉工具页里那个自带的可视化视窗——工具窗口是跟主窗口共存的，直接在**主窗口的视窗**上操作；
- **③** 工具页加「在线/离线」开关；
- **⑤** 离线时：工具打开期间，主 2D 视窗临时显示所加载文件的图像；退出工具后自动恢复实时/采集图。

上一轮已经把取点逻辑抽成 `logic/PixelTo3DService`，本轮不再动它。
**注意**：主窗口**已经有**一个 2D 点击取点（`MainWindow::on2dPixelPicked`：点击→3D 黄球＋填「相机目标点」卡片），
那是既有功能，本轮**不要改它的行为**，只在离线模式下把点击**再转发一份**给工具页。

## 判据（逐条可验证）

1. `cmake --build build --config Release` 退出码 0；
   `ctest --test-dir build -C Release --output-on-failure` 仍然 2/2 通过，
   且 `unit_tests` 的用例总数不得低于 **24 类 / 270 passed**（不得改 `tests/`）。
2. 工具页不再有内嵌视窗：`src/ui/ToolsPanel.{h,cpp}` 里 **不再出现** `m_p2dView` 与
   `new Image2DView`；`ToolsPanel.cpp` 里不再 include `ui/Image2DView.h`。
3. 工具页新增模式开关：控件 objectName 为 `p2d_mode`，两个选项文案包含「在线」「离线」，
   **默认「离线」**；切换时立刻反映到可用的输入项上（在线时数据文件夹/图像/内参/外参整组禁用并有提示，
   离线时像素输入框仍可用）。
4. `src/ui/Image2DView` 新增三个成员（签名照抄）：

```cpp
    // 临时把画面冻结成给定图像（离线工具用）。冻结期间 updateFrame() 仍更新
    // "最后一张真实帧"，但不改屏幕上的画面，也不会丢掉实时数据。
    void setFrozenImage(const QImage& image);
    // 解冻：立刻用最后一张真实帧重绘（没有真实帧时清空画面）。
    void clearFrozenImage();
    bool frozen() const;
```

5. 工具页新增两个信号与一个槽（签名照抄，MainWindow 要接）：

```cpp
signals:
    // 离线模式：请主窗口把主 2D 视窗冻结成这张图
    void pixelTo3DOfflineImageRequested(const QString& imagePath);
    // 离开离线模式 / 关掉工具页 / 清空目录：请主窗口解冻
    void pixelTo3DOfflineImageEnded();
public slots:
    // 主 2D 视窗上的左键点击（离线取点）：填进像素输入框并立刻重算
    void onMainViewPixelClicked(int x, int y);
```

6. `MainWindow` 接线（行为要求）：
   - 收到 `pixelTo3DOfflineImageRequested(path)` → 把主 2D 视窗冻结成该图（加载失败要给可读提示，不要静默）；
   - 收到 `pixelTo3DOfflineImageEnded()` → 解冻；
   - `m_view2d::pixelClicked` 到达时：**若工具页当前处于离线模式**，除既有 `on2dPixelPicked` 之外，
     再调用 `m_toolsPanel->onMainViewPixelClicked(x, y)`；否则一切照旧；
   - 工具页被关闭（`hideEvent`）或切到在线时，必须发 `pixelTo3DOfflineImageEnded()`，
     ——"退出工具自动恢复实时/采集图"这条靠它。
7. 手动在「数据文件夹」里打字要能刷新「2D 图像」下拉（现在只有点「浏览」才刷新，是既有毛病）：
   `m_p2dDir` 的 `textChanged` 也要触发刷新；目录里没有 png 时不报错崩溃，给出「该目录下没有 png 图像」这类提示。
8. 外参文本**非空**但解析失败时，不允许静默忽略：直接报 `相机外参：<解析错误>`（这是上一轮遗留的边角输入，
   本轮收口）。
