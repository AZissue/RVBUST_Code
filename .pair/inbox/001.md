# 001 — 抽出「像素→3D」共享服务（在线/离线共用）

## 背景

`像素→3D` 工具的取点逻辑现在直接写在 UI 里：`src/ui/ToolsPanel.cpp` 的
`updatePixelTo3DResult()` 自己判断点云是否与图像像素对齐，再分别调用
`PixelTo3DTools::alignedIndex/pointAt` 或 `PixelTo3DTools::buildProjectedIndex/queryIndex`，
失败提示也在 UI 里拼。

下一轮要做的「在线」功能（连接相机拍完照后，在主 2D 视窗左键点像素 → 主 3D 视窗显示对应点）
必须复用**同一条**取点链路，不能再复制一份。所以本轮先把这段逻辑抽成一个共享服务，
并让工具页的离线路径改走它。

**本轮只做抽取 + 接线，不改任何界面结构、不加开关、不动主窗口视窗。**

## 判据（逐条可验证）

1. `cmake --build build --config Release` 退出码 0；
   `ctest --test-dir build -C Release --output-on-failure` 仍然 **2/2 通过**
   （`unit_tests` 与 `measurement_truth` 的用例数不得下降）。
2. 新增 `src/logic/PixelTo3DService.h`，公开 API **必须**与下面这段签名一致
   （Codex 会直接 `#include "logic/PixelTo3DService.h"` 写单测；名字、参数顺序、返回类型都不能改）：

```cpp
#pragma once
#include <array>
#include <string>
#include <vector>
#include "logic/PixelTo3DTools.h"   // 复用其中的 Intrinsics（fx/fy/cx/cy）

namespace PixelTo3DService {

// 一帧数据 + 像素↔点云的对应关系。所有指针只在调用期间有效，不接管所有权。
struct Source {
    const std::vector<double>* xyzMm = nullptr;  // n*3，毫米；必须非空
    int imageWidth = 0;                          // 2D 图像宽（像素）
    int imageHeight = 0;                         // 2D 图像高（像素）
    PixelTo3DTools::Intrinsics intrinsics{};     // 非对齐点云需要
    bool hasIntrinsics = false;                  // 调用方是否提供了内参
    const double* extrinsics16 = nullptr;        // 4×4 行主序，可为 null（点云已在相机系）
    const std::vector<double>* correspondMap = nullptr;  // n*2（3D 点索引 → 像素），可为 null
};

enum class Status {
    Ok,                 // 找到 3D 点
    NoData,             // 点云为空 / 图像尺寸非法
    MissingIntrinsics,  // 点云与图像不对齐，但没给内参
    InvalidIntrinsics,  // 给了内参但 fx/fy <= 0
    OutOfRange,         // 像素坐标不在图像范围内
    NoPointAtPixel      // 该像素没有有效点（背景 / 无效深度）
};

struct Query {
    Status status = Status::NoData;
    std::array<double, 3> pointMm{};   // 仅 status == Ok 时有效
};

bool hasData(const Source& src);
Query query(const Source& src, int pixelX, int pixelY);
std::string statusText(Status status);
std::string formatPoint(const std::array<double, 3>& pointMm);
}
```

3. 分派顺序必须与旧实现一致（旧实现的行为不能在重构里悄悄变）：
   ① `xyzMm` 为空 / 尺寸非法 → `NoData`；
   ② `correspondMap` 非空 → 用 `PixelTo3DTools::buildCorrespondIndex` + `queryIndex`；
   ③ 否则 `xyzMm->size() == imageWidth*imageHeight*3` → 用 `alignedIndex` + `pointAt`（对齐数据走直查）；
   ④ 否则走投影：`hasIntrinsics == false` → `MissingIntrinsics`；`fx<=0 || fy<=0` → `InvalidIntrinsics`；
      其余用 `buildProjectedIndex` + `queryIndex`。
   ⑤ 像素越界 → `OutOfRange`；查到但点无效（非有限值 / 索引 -1）→ `NoPointAtPixel`。
4. `src/ui/ToolsPanel.cpp` 里**不再直接出现**这些调用：`PixelTo3DTools::alignedIndex`、
   `pointAt`、`buildProjectedIndex`、`buildCorrespondIndex`、`queryIndex` —— 它们只允许出现在服务实现中。
   （复核方式：对 `src/ui/` 目录 grep 这 5 个名字，结果为空。）
5. `formatPoint()` 输出 `"%.3f, %.3f, %.3f"`（mm，3 位小数，英文逗号 + 空格），与工具页结果行现在的格式完全一致；
   `statusText()` 返回可读中文，且对 `NoPointAtPixel` 的文案包含「该像素无有效 3D 点」。
6. 工具页离线行为不变：同一文件夹 + 同一像素 + 同一内参/外参，改后结果与改前**逐位相同**；
   内参缺失/非法时仍给出与改前语义一致的提示（文案允许等价改写，含义不能变）。
