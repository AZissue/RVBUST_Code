# 扫描原型的日志、状态和帧反馈

保留原型顶部功能带、大型 3D 视区及右上角当前帧 2D 面板，复用主程序的日志交互、质量卡指标和机位时间线信息结构。

## 日志

主程序 FloatingLogPanel 与原型共用 ui_common.activity_log.ActivityLogPanel。默认保留最近 2,000 条，每条显示时间、等级、可选帧号和任务名。支持等级过滤、关键词搜索、自动滚动开关、复制当前筛选结果、导出 UTF-8 文本及清空。主程序浮动模式折叠保留标题栏；扫描原型的底部模式收起整块面板，再由底部日志按钮展开。关闭面板同步取消日志按钮勾选。

后台 core.utils.logger 经 Qt 排队信号进入 GUI；UI 操作日志也写入现有轮转日志文件，通过 activity_owned 标志避免重复显示。关闭窗口移除 handler；显示历史上限不影响原有文件轮转策略。界面日志每条最多显示 4,000 字符，多行压为一条，完整异常仍以文件日志为准。隐藏面板只存记录，显示时更新；可见面板批量更新，普通追加复用现有文档。

扫描原型日志默认收起，展开后停靠在工作区下方，默认高度约 200px；上下分隔条允许调整高度，重新展开恢复上次高度（受当前窗口可用空间约束）。标题栏不再拖成浮窗，“−”和“×”均收起面板。展开和收起不重置点云旋转、缩放、平移或旋转中心。日志展开时隐藏重复的最近消息行；小窗口同时隐藏来源详情行（来源仍可在帧列表悬停查看），让 2D 图像和编码圆数据入口保持可访问。压缩到极小的视区时，2D 面板自动精简详情，完整数据仍在详情窗口中。主程序已有浮动布局保持原有方式。

## 状态与质量卡

状态栏区分原始有效点数、当前载入点数、实际绘制点数。原始点数由 source_points 提供，未提供时使用图层现有点数，不根据文件名推断。设备描述不代表设备已连接；连接文案由 set_connection_status 明确提供。文件操作使用不定进度，扫描保留原有进度。

质量卡和左侧帧状态共同读取 CloudLayer.registration。基准帧、未评估、成功、需关注、失败分别呈现；无配准结果的导入点云不标为成功。缺少内点率或 RMS 时显示“—”，不由共有圆数推算精度。RMS 是帧间拟合残差。

```python
workbench.set_frame_registration(
    layer_index=1, reference_id=1, shared_markers=12,
    inlier_ratio=0.92, rms_mm=0.35, accepted=True,
    suggestion='配准通过，可继续扫描',
)
```

JSON 图像结果可带同名 registration 对象，字段同上述接口。set_frame_registration 更新失败状态时同步取消该帧共有红圈。新结果由控制器提供，UI 不自行设定质量阈值。

## 帧导航

左侧沿用项目树：帧名显示状态，悬停查看参考帧、共有圆数、内点率、误差和来源；选择帧联动图像与质量卡。复选框保持控制可见性。“撤销末帧”删除最后一层，普通“撤销编辑”可恢复。原型不自动重算后续配准变换。

“重拍当前帧”默认禁用。控制器接好 recapture_requested(index) 并调用 set_recapture_available(True) 后启用，由控制器负责采集、重算受影响帧及更新结果；原型不会伪造真实重拍。

八帧实测回放显示缓存中的真实参考帧和 RMS；旧缓存未保存内点率则显示“—”。显示抽样和原始 PLY 不变。
