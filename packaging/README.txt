手眼标定数据收集助手 绿色版（免安装）
==================================================

一、运行前提
  - Windows 10/11 64 位。
  - 无需安装 VC++ 运行库、RVC 或 HandEyeSDK（已全部内置在程序目录）。
  - 相机为 GigE 网线连接时，请把电脑网卡 IP 设为与相机同一网段，
    并开启巨型帧（Jumbo Frame，建议 9014 字节）；如连接不上请放行防火墙。
  - 如需固件升级/相机管理，可另装 RVC 官方软件（不影响本程序运行）。

二、使用
  - 双击「start.bat」或 HandEyeCalibrationTool.exe 即可运行。
  - 标定数据默认保存在本目录 data\ 下；若该目录不可写，会自动改用
    「文档\HandEyeCalibData」并在启动时提示。

三、日志（排障用）
  - logs\runtime_<日期>.log   技术运行日志（连接/采集/识别/崩溃信息）
  - logs\app_<日期>.log       操作日志（用户操作记录）
  运行失败时把 runtime 日志发给开发人员即可定位。

四、常见问题
  - 启动就报缺少 DLL：确认整个文件夹被完整解压（不要只拷 exe）。
  - 找不到相机：检查网卡 IP/巨型帧/防火墙/相机供电。
  - 3D 窗口无点云：检查 3D 曝光与采集模式（程序会自动选全帧模式）。
