# UI 图标目录

把自定义图标图片放到本目录，程序启动时自动加载；**没有对应文件的位置保持 emoji 兜底**，可以只替换部分图标。

## 图片要求

- 格式：PNG（推荐，支持透明底）或 SVG
- 尺寸：按钮图标建议 16×16 或 24×24 px，Tab 图标 16×16 px（高分屏可提供 2 倍尺寸，Qt 自动缩放）
- 风格：深色主题背景上使用，建议浅色线条/填充图标
- 文件名：严格按下表命名（小写 + 下划线）
