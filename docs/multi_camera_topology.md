# 多相机星型 / 链式标定

新版多相机工作区顶部“外参标定”组增加方式入口，默认显示“星型标定”。点击后可选择星型或链式；入口文字跟随当前方式。

## 操作

1. 固定相机位置，选择标定方式并采集各路标定帧。
2. 使用全局唯一编号的编码圆，完成检测；后台识别启用时，计算外参会等待输入帧识别完成。
3. 点击“计算外参”，检查配对误差、内点率及到参考相机的路径。全部参与相机通过门禁后进入扫描。
4. 撤掉标记物并采集扫描帧，执行拼接。结果可视化窗口可按配对查看重合及逐点误差。

星型要求每台相机与参考相机直接共视；N 台相机需要 N−1 个直接配对。

链式自动尝试两两共视配对，不要求按设备编号排列，也不要求每台相机都能看到参考相机。系统从 RMS ≤ 2 mm、内点率 ≥ 50% 且矩阵有效的配对中，以参考相机为根逐步选择跨越已连接和未连接相机的最低 RMS 边，构建连接树。树边误差相同时优先较高内点率，再按相机 ID 确定顺序。

例如 `cam2 → cam1 → cam0`：`T(2→0) = T(1→0) × T(2→1)`。每对相邻相机可以看到不同的编码圆，但同编号必须对应同一个物理标记，不能混用不同标定板上的重复局部编号。标定时各台相机及标记物保持固定。

## 门禁与限制

- 已连接相机与当前标定帧中的相机作为本次参与集合；缺少任一路输入或存在无法到达参考相机的节点时，标定失败。
- 每条实际采用的边必须通过配对门禁。链式未采用的候选配对失败原因记录在日志中；结果表显示实际采用的树边，路径说明显示无法连接的相机。
- 星型不使用中间相机绕过直接共视要求。链式仅使用合格边复合；普通扫描拼接缺少参与相机的扫描帧时拒绝执行。显式勾选 DB 数据仍按用户选择的帧拼接，其相机必须有有效外参路径。
- 逐点 RMS 属于每条配对边，不能作为整条链末端的绝对精度；长链可能积累误差。目前不执行闭环或全局联合优化，即使存在闭环也只采用连接树。
- 切换方式保留标定原始帧，清除内存中的旧外参及扫描工作流状态；DB 原始数据保留。需要重新计算才能继续扫描。
- 方式、参与相机与实际采用的配对随显式保存的会话持久化；尚未计算外参时也保存方式。旧会话缺少方式字段时按星型处理，加载时重新检查质量与连通性。
