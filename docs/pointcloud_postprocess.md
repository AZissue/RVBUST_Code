# 点云后处理工作区

适用：新版工业工作区中的多相机外参、移动拼接和转台模式。

## 入口和操作

主程序标题区点击“点云后处理”。窗口保持深色工业风格，操作集中在顶部及左侧，3D 画布不增加工具栏。当前任务忙时入口禁用。

- 入口优先载入主 DB 勾选的点云，其次载入选中项或当前预览项；也可在后处理窗口的“项目 DB”页重新选择，再点“从 DB 载入”。项目 DB 与主程序读取同一份记录，处理图层使用独立副本，窗口中的勾选不改变主程序预览。
- “处理图层”支持 Ctrl/Shift 多选、勾选显隐、右键删除及恢复上次删除；选中根节点代表全部图层。删除仅影响临时处理区。
- 多边形框选：左键加顶点，Alt+左键撤回顶点，右键或双击封闭，Esc 取消。封闭后显示框内/框外完整点数，再点击左侧“保留框内”或“保留框外”。舍去部分生成分割分支，仍可显示、合并、导出或写回。
- 合并按选中图层顺序连接点数据，不执行配准、变换或自动去重。有色图层保留原颜色，无色部分使用默认显示色。
- 下采样作用于当前处理图层。体素尺寸单位 mm，体素内坐标与颜色取均值；随机抽样按保留百分比无放回选点。
- 撤销覆盖分割、合并和下采样，最多 8 步。载入和显隐不进撤销栈；删除采用单独的回收历史，并清空旧编辑撤销记录，防止同一图层被重复恢复。
- “导出选中”输出选中图层完整点数据，与显隐无关；多层导出合并为一个 PLY。显示抽稀不影响处理与导出点数。
- 外部 PLY/PCD/XYZ/PTS 可通过“打开点云”载入。先在“处理参数 → 外部文件”选择源单位 mm 或 m；内部和导出均统一为 mm。

## 写回和保存

“写回 DB”每次接收一个选中处理图层，多层需先合并或分别写回。主 DB 新增“后处理结果”分组，内含独立 PLY，可继续预览、导出或再次载入处理；原始帧、拼接结果与工作流数据不被替换。

写回只更新当前临时项目。需要保留到正式会话时，在主程序显式保存会话；没有后台自动保存。关闭后处理窗口时，未写回或导出的处理图层需要确认丢弃。

记录沿用既有 `kind=result` 和 `purpose=后处理结果`，不增加会话格式版本。`source_ids` 指向直接来源记录；来源变化会沿拼接/后处理派生链标记结果失效。载入及写回均校验项目目录、来源 UID、几何版本与失效状态，避免旧副本写入新项目。外部点云允许无 DB 来源。

## 实现边界

- 正式算法与工作图层位于 `src/core/postprocess/`，界面调度位于 `src/ui_v2/postprocess/`。生产代码不导入 `prototypes/`；原型继续保留作对照。
- 复用 `FrameBrowser`、`DbProperties`、`IndustrialViewer`、`WorkerThread` 与主程序图标/样式。批量替换显示图层只刷新一次，通常保留当前导航状态。
- 文件读取、分割、合并、下采样、导出和 DB 写回在后台运行。编辑使用独立只读 XYZ/RGB 数组；加载、写回和失败恢复不会覆盖来源几何。必要任务接入主程序线程清理；处理期间禁止关闭窗口或重复提交操作。
- 当前仅处理 XYZ/RGB；非有限坐标过滤，法线、强度和其他自定义 PLY 字段不传递。若需要原文件全部字段，使用主 DB 的原文件导出。
- 多边形分割为沿视线的正交投影裁剪，视线前后所有点一起参与，不按深度区分；视区尺寸改变会取消暂存框选；视角改变后必须重新框选。
- 原始多相机点云沿用各自存储坐标，不自动应用外参。需要在同一坐标系处理时，应先完成拼接并载入对应结果。
- 编辑撤销与回收图层保存在内存中，关闭窗口后不恢复；正式会话保存的是写回 DB 的结果。

## 验证

`test_postprocess.py` 覆盖算法、后台执行、共享 DB、三种模式入口、分割守恒/视角失效、合并颜色、撤销/回收、原文件保护、写回/单帧导出/会话恢复、来源失效、写入失败及关闭门禁。

UI 检查包括 1440×900 与 1050×650 离屏截图；离屏使用软件兼容预览。实体相机采集、原生 GPU 性能、大规模点云内存压力与客户机打包尚未实测。
