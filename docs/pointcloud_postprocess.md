# 点云后处理工作区

适用：新版工业工作区中的多相机外参、移动拼接和转台模式。当前界面只有一棵项目 DB 树，取消“处理图层”页、“从 DB 载入”和“写回 DB”按钮。

## 操作流程

1. 主程序顶部功能栏的“后处理”组点击“点云后处理”，默认显示主 DB 勾选/选中/预览的点云。
2. 在左侧 DB 树点击点云或帧，直接读取并显示。勾选多项可叠加显示，Ctrl/Shift 多选也可载入多项；不再维护第二棵图层树。当前点云用于框选和下采样，合并作用于当前显示的多项点云。
3. 使用顶部的多边形框选、合并点云或“下采样”。单个“下采样”按钮打开独立参数弹窗，选择体素下采样或随机抽样，设置尺寸（mm）或保留比例后点击“执行下采样”；取消不写 DB。处理与写入在后台完成，成功后自动在 DB 的“拼接结果”分类下新增后处理帧及独立点云叶子、刷新树并选中结果，继续操作该结果即可。
4. 处理结果已在当前临时项目 DB 中，不必再点击写回。需要保存为正式项目时，仍在主程序显式保存会话；没有后台自动覆盖正式会话。

顶部“导入点云”先打开单位弹窗，确认 mm/m 后点击“选择文件…”进入文件选择；两处任一取消均不写 DB。“颜色统一”弹窗显示当前输入层数/点数、参考层、完整参数、同坐标系确认与局限说明；长内容可滚动，执行/取消按钮固定可达。三个参数弹窗每次新建、关闭即销毁，在当前后处理窗口内记忆修改过的参数（包括取消前的修改），再次打开仍会重新校验。取消、Esc 和窗口关闭不启动 worker、不改变显示或撤销栈；默认按钮为取消。 工作区清理后不再接收迟到的后台界面回填，也不能再次派发任务；已启动且必须完成的写盘仍等待完成。执行使用接受时的参数快照，并复核来源修订与项目，输入变化时需重新打开。直接程序调用 open_file(unit='mm') / correct_colors(params=ColorParameters(...)) 仍可显式传参，不依赖界面控件。

界面保持主程序深色工业风格。DB 树与左下属性区域可拖动调整，左下只保留“数据属性”和“3D 显示”；选中记录、叶子或虚拟帧时自动显示对应属性，无选择时显示提示。所有处理入口均收纳在顶部操作区，顶部只作功能入口，导入点云、下采样、颜色统一的参数均在各自独立模态弹窗设置，不再使用顶部下拉参数面板，均不占用属性区。后处理的 3D 显示不提供“编码圆圆心与编号”，主程序仍保留该选项。多边形分割集中在点云视窗右上角的紧凑图标工具条，详细操作见鼠标悬停提示和底部状态栏。窗口内的勾选与主窗口预览选择独立；两处共享同一个 DB 和结果记录。

## 分割、合并与下采样

- 顶部“多边形框选”进入绘制；右上角图标从左到右为：封闭、撤销顶点、保留框内、保留框外、快捷删除、取消。左键加顶点，Alt+左键撤回顶点，右键或双击封闭，Esc 取消。封闭后底部显示完整点数，再选择保留范围。
- 后处理与主程序使用同一套导航：左键拖动旋转、右键拖动平移、中键单击命中点云设置旋转中心、滚轮缩放、F/Z适配。中键不进入拖动，未命中则保持中心；设置中心保持当前投影不跳动。绘制顶点期间中键仍可用，视角或中心变化后清除旧框选并重新选择。多边形封闭后锁住旋转、平移、缩放和适配视图，应用或取消后恢复，避免沿旧投影裁剪。渲染器兼容回退后仍遵循同样规则。
- 分割的保留部分与另一部分一起原子写入 DB，任何一步写入失败均回滚。默认只勾选保留部分；另一部分作为独立结果保留在 DB，可随时再勾选查看。
- 多边形裁剪沿当前视线作正交投影，不按深度区分。视区尺寸变化会取消暂存框选；改变视角后必须重新框选。
- 合并按 DB 输入顺序连接点数据，不配准、不变换、不自动去重。有色数据保留颜色，无色部分使用默认显示色。
- “下采样”弹窗在同一窗口内记住上次方法和数值；体素尺寸单位 mm，体素内坐标与颜色取均值；随机抽样按保留百分比无放回选点，预计 0 点时禁止执行。每次成功操作自动生成新 DB 结果，来源数据不覆盖。
- 显示抽稀只影响预览，不影响处理与导出的点数。

## 颜色统一（1.13.10）

顶部“颜色统一”作用于当前显示的 DB 点云，独立参数弹窗展示输入数、参考层、空间尺度、重叠距离、强度、增益上限及估计样本上限。左下仍只有数据属性和3D显示；“统一颜色”显示模式与本功能无关，后者实际生成独立RGB数据。

- 默认强度60%，增益上限1.5（下限为其倒数），可配置强度大于0且不超过100%、增益上限大于1且不超过2；强度0%或上限1在执行前以中文参数回显拒绝，不启动worker、不写DB。弹窗数值控件滚轮禁用，未聚焦方向键禁用，增益步长0.05避免一次方向键跌到1。空间尺度默认30 mm，重叠距离默认2 mm，估计上限默认每层20,000点、最多100,000点；距离阈值明确以mm显示，不自动猜测未配准姿态。
- 单份点云走空间低频校正；多份点云必须处于同一坐标系，弹窗需确认。多份原始帧输入拒绝，请先完成正式拼接；导入/结果点云仍由操作者保证已对齐，功能不配准、不应用外参。默认参考为当前活动层，弹窗可切换，参考颜色不变。
- 内部RGB为0..1浮点。整层任一点的通道差超过1e-6即按RGB处理；灰度目标只估计等值亮度增益，校正输出三通道严格相等。RGB按通道估计并受增益上限约束，不整云填平均色。
- 无色及混合有色/无色输入整个批次拒绝，不补造默认蓝色或所谓原始色。黑色/饱和颜色（任一通道不在0.02..0.98）不参与估计，但仍保留在输出点序中。有效颜色或邻域样本不足会拒绝，不能从纯黑/纯饱和数据反推原始颜色。

多云算法：对每层做固定等距索引抽样，以KD树建立参考与目标的双向最近邻，仅接受阈值内互为最近邻的候选。至少24个有效颜色内点；候选距离中位数超过阈值75%、各通道均缺少动态范围、对数颜色比MAD过大或内点不足时跳过。使用对数颜色比的逐通道中位数及MAD剔除离群。估计增益超出0.4..2.5视为不可信，接受后再施加强度及配置的上下限。空间不重叠的层不会强行匹配；跳过层保持原颜色并随同分层输出，若所有目标都无法可靠校正则拒绝整次操作。

单云算法：没有逐点拍摄机位标签，不做伪帧间匹配。以尺度一半的固定空间格聚合局部对数颜色中位数（每格至少4个样本），再用尺度为标准差的高斯邻域平滑（最多32个格、半径2.5倍尺度、至少24个样本支持），以有界近邻图识别几何断开的区域，使用各区域的对数中位颜色作为锚点，估计缓慢变化增益；避免把互相分离的不同材质拉到同一全局颜色。连续表面内仍无法可靠区分材质与照明，不做语义材质识别。对全量点用最多8个附近格的平滑场插值，小邻域支持不足处使用单位增益。不是逐体素独立拉成同一均值。空间尺度越大，局部变化越弱；大块真实材质、阴影、反光与照明无法仅凭一份PLY可靠分离，可能被改变，需降低强度或保留原始结果比较。

强度采用对数域插值。零参数拒绝；估计后最大绝对对数增益小于0.5%或变化超过0.5%的点不足1%时，判定“无可应用校正”，保留诊断但不发布新帧，不改变当前显示。重复处理只有仍存在超过门限的可估计变化才会生成结果，不承诺单云算法数学幂等。全量应用按65,536点分块；仅在最终数值保护时clip到0..1，若超过1%的通道值需要高端截断，按各通道安全指数的8192档直方图保守求全局k，统一缩小对数增益，使实际截断不超过1%；报告原始截断、k与实际强度。仅在k小于0.2或实际最大幅度小于5%时拒绝，并说明受高光限制，不靠大量截断伪造效果。固定输入顺序和参数下估计与输出确定；抽样并非视口抽稀，全量点均处理，最终结果仍需全量颜色存储，不能宣称常量总内存。

每个输入各生成一个独立结果，点数、点序、XYZ不变，各自直接来源为对应输入UID；不自动合并，不覆盖源PLY。同批输出原子发布、归入一个后处理帧、全部自动勾选显示，可导出、撤销、删除恢复并随完整会话保存。状态和日志回显本次尺度、强度、增益上限、样本上限、重叠距离，以及每层样本、节点/支持节点、几何分区、重叠内点、估计/应用增益、变化超过5%/10%的点比例、分布保留率、截断、实际强度/k和跳过原因。分布保留率为确定性样本亮度p90-p10之比，低于60%时提示“可能抹平材质，建议降低强度”，不擅自改变用户参数。指标不等于已知接缝或真实材质真值。处理期间入口禁用、关闭等待worker边界，发布前复核项目与来源修订。

顶部“对比原色/返回校正结果”仅保留本次操作的来源与结果UID，按需从DB重新读取，不常驻第二份全量颜色缓存；读取期间沿用忙碌门禁。重开窗口后可照常从DB选取来源/结果比较，本窗口快捷切换只针对最近一次成功的颜色操作。

该功能是色彩差估计与视觉缓和，不是摄影测量级真彩还原。未知曝光响应、非线性相机色调、反光/遮挡、几何错位和缺失逐点来源都可能限制效果；合成离线统计改善不代表真实鞋面色彩已还原。尚未实现基于近重复点或用户接缝选区的局部匹配；连续大块材质仍可能被当成照明。

## 撤销、导入和导出

“撤销处理”保留当前窗口最近8次成功操作的记录。撤销会把本次生成的整批结果移入 DB 回收区，重新显示之前的数据；不会删除原始帧。需要恢复时，使用主窗口 DB 的回收区操作。若结果已有其他派生数据，或者来源被修改/删除，撤销会拒绝执行以保护依赖。

“导入点云”支持 PLY/PCD/XYZ/PTS。点击顶部“导入点云”，在独立参数弹窗选择源单位 mm 或 m，再点击“选择文件…”；读取后自动加入当前 DB 并显示，内部及导出统一为 mm。

“导出选中”直接导出 DB 数据：单项复制完整 PLY，保持源文件字段；多项读取后合并输出 XYZ/RGB。显隐与导出选择独立。关闭后处理窗口不会丢弃已经写入 DB 的结果；处理或写入尚未结束时禁止关闭。

## 实现与数据边界

- `src/core/postprocess/` 只保留几何与文件工具；`src/ui_v2/postprocess/` 负责单一 DB 界面、后台任务及结果回填。正式程序不导入原型，已移除独立图层树及内存图层撤销管理器。
- 复用 `FrameBrowser`、`DbProperties`、`IndustrialViewer`、`WorkerThread` 和主程序样式/图标。只缓存当前显示的只读点数据；历史处理结果保存在 DB，不把整条编辑历史留在内存。
- `FrameDatabase.publish_results()` 将相关分支作为一个事务提交，只在全部点云和索引成功后通知观察者。既有 `publish_result()` 接口及会话格式保持兼容。
- 结果沿用 `kind=result`、`purpose=后处理结果`，`source_ids` 记录直接 DB 来源。来源变化沿派生链传播失效；载入、处理写入、导出和撤销校验项目目录、来源身份及几何版本。
- 设置复选框时不重建树；只有后台操作完成后的 Qt 回调刷新结果节点，避免原生 `QTreeWidgetItem` 在通知过程中被销毁。载入在飞时保留最新选择，旧结果不会覆盖新选择。
- 几何处理只传递 XYZ/RGB，不传递法线、强度等自定义字段；非有限坐标过滤。需要原文件全部字段时可直接导出单项 DB 原文件。
- 原始多相机点云使用各自存储坐标，不自动应用外参。需同一坐标系处理时，应先拼接，再处理对应结果。

## 接缝局部融合（1.13.22）

单云在低频场之外增加颜色条件局部残差校正，解决近重合点共享空间增益而色差保留的问题。“单云接缝融合”默认60%，0关闭；与校正强度相乘，仍受统一增益和高光保护限制，多云仍走原重叠匹配。邻域取最多24个确定性估计样本，半径为空间尺度的1/4，至少4个有效支持；对数通道色差用衰减核筛选，超过0.55及黑色/饱和点不参与局部融合，降低跨黑白图案混色。该方法仍无法辨别同等色差的真实纹理与曝光差，细小纹理可能变软，薄层间距小于邻域时也需谨慎；建议从默认参数对比，必要时降低融合强度或空间尺度。没有来源机位标签时不能承诺完全消除接缝。
