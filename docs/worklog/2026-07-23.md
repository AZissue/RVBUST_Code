## 已完成事项

### 1. 修复 `--demo` + `--autoquit` 退出段错误

- **现象**：`RvcVisionStudio.exe --demo <ply> --autoquit 5` 退出时崩溃，gdb 回溯指向 `QtNodes::BasicGraphicsScene` 析构链，触发位置在 `QGraphicsView::scene` 访问。
- **根因**：`MainWindow` 析构顺序错误。`inner_`（内部 `QMainWindow`）比 `BasicGraphicsScene` 先析构，`FlowView` 析构时访问已释放的 scene。
- **修复**：
  - `src/ui/MainWindow.h`：新增 `std::unique_ptr<QtNodes::BasicGraphicsScene> scene_`，并**声明在 `inner_` 之前**，利用 C++ 成员析构顺序保证 `inner_` 先销毁、`scene_` 后销毁。
  - `src/ui/MainWindow.cpp`：scene 不再挂入 Qt 对象树，改由 `unique_ptr` 持有；在 `.cpp` 中默认实现析构函数，确保 `BasicGraphicsScene` 完整类型可见。
- **验证**：
  - `RvcVisionStudio.exe --demo test_cloud.ply --autoquit 5` → 退出码 0，无崩溃。

## 追加：ROI 交互重写（2026-07-23 深夜）

### 问题

- 2D ROI 视图只能画新矩形，不能拖动或调整边缘；Y 方向在特定点云下难以拖出有效值。
- 3D 视窗的 RubberBandPick 框选只能一次性画矩形，无法交互式移动或调整包围盒。

### 实现

- **Roi2DView 重写**：状态机交互（空白画矩形 / 内部拖动 / 边缘角调整），滚轮缩放、右键平移视图，Y 轴翻转符合直觉。
- **Viewport3D 重写**：用 `vtkBoxWidget2` + `vtkBoxRepresentation` 替换 RubberBandPick；
  支持拖 7 个 handle 调整大小、中键/右键整体调整；禁用旋转保持轴对齐；
  `setRoi()` / `roiPickedCallback` 双向同步。
- **RoiEditDialog**：3D 模式下 spin box 与 box widget 实时双向同步。
- **MainWindow**：`onRoiPicked` 增加轻量防抖，避免 box widget 高频触发导致卡顿。

## 追加：修复标题栏按钮无响应（2026-07-23 深夜）

### 问题

自定义标题栏上的最小化/最大化/关闭按钮点击无反应。
根因：`nativeEvent` 的 `WM_NCHITTEST` 处理中，`childAt()` 误用了屏幕坐标 `x, y`
（应为 `mapFromGlobal` 后的本地坐标 `pos`），导致按钮区域找不到子控件，
整个标题栏被标记为 `HTCAPTION`（可拖动），按钮收不到鼠标事件。

### 修复

`src/ui/MainWindow.cpp`：`childAt(QPoint(x, y))` → `childAt(pos)`。

### 验证

- 构建 Release 通过。
- `unit_tests.exe` / `--selftest` / `--smoke` / `--demo --autoquit 3`：均 PASS。
