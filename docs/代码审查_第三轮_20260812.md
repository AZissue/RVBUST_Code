## 🔴 P0（必须修）

### P0-1 删除中间机位后继续拍摄 → add_frame 必崩 + 节点残留 + 幻影点云（链报废）

- **位置**：`src/core/mobile_chain_workflow.py:188-199`（`_remove_station_from_chain` 只删节点不恢复图连通性）＋ `src/core/chain_stitcher.py:151`（`get_transform` 无 try/except）
- **问题**：链式拓扑边是"新→前一机位"的树。`delete_station` 删除**中间**机位后，其下游子树的路径被切断（BFS 死胡同），残留节点的 `T_world` 与位姿图均未重算。之后继续拍摄：新帧与断连组件匹配 → `add_edge` 成功 → `get_transform` 抛 `ValueError: 位姿图中找不到终点`，**未捕获**，从 `add_frame` 冒出；且崩溃点位于 `edges.append`/`pose_graph.add_edge` 之后 → **node/edge 残留**（`T_world=None`）→ 后续每次拍摄持续崩溃；`get_merged_pointcloud` 对残留节点用 `eye(4)` 变换，**原始坐标系点云叠加到参考系原点（幻影点云）**。
- **实跑证据**（4 机位链删除 station_2 后继续拍）：
  ```
  已删除 station_2, 剩余节点: ['station_1','station_3','station_4']
  💥 add_frame 崩溃: ValueError : 位姿图中找不到终点 'station_1'
  崩溃后 nodes: ['station_1','station_3','station_4','station_5']   ← 残留
  崩溃后 edges: [('station_4','station_3'), ('station_5','station_4')] ← 残留
  station_5 T_world: None
  💥 再拍 station_6 崩溃（持续崩溃）
  get_merged_pointcloud 点数: 50（含幻影点）
  ```
- **修复建议**：① `chain_stitcher.add_frame:151` 的 `get_transform` 包 try/except，失败时回滚 `nodes/edges/pose_graph`（对齐 135/142 行失败清理模式）；② `_remove_station_from_chain` 删除非叶子节点后，从参考节点重新 BFS 刷新剩余节点 `T_world`，不可达节点一并移除并返回警告；或最简：删除会破坏连通性的中间节点时直接拒绝。
