不是"缺可读报错"——`test_ui_smoke.py:64-67` 的 `[0] 环境` 段**已经**打印了人看得懂的 `[FAIL] 仓库根定位 … | 未找到`；缺的是**它后面那段 `[FAILED] n 项失败` 汇总被 `:71` 的模块级 import 截断**。因此批 4.7 的价值是"补收口"，不是"补报错"。
