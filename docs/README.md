### 使用建议
- 查看 **版本变更与缺陷修复** → 先看项目根目录 `CHANGELOG.md`
- 修复 **core 算法 bug** → 先看 `code_review_bugs_v3.md` 与 `代码审查_第四轮_20260818.md`
- 修复 **UI/数据流/打包/测试基建** → 先看 `代码整体审查与完善建议.md` 与 `工程化审查_20260807.md`
- 评估 **新功能（离线拼接 / 手眼）** → 看 `功能扩展规划_离线拼接与机器人手眼配合.md`

## 三、维护规则

1. **新增审查报告**：如果与当前文档同源，用新版替换旧版；旧版移入 `archived/`。
2. **方案类文档**：实现并验证后，移入 `archived/`；未实现的规划保留在根目录。
3. **重复/中间版本**：直接删除，只在根目录保留最新版。
4. **截图/辅助素材**：随对应文档一起归档或删除。
