## 三、维护规则

1. **审查报告**：只保留最新一轮在根目录；旧轮次直接删除或随冲刺批次归档（结论已并入新报告核验表）。
2. **方案类文档**：实现并验证后，移入 `archived/`（建议按冲刺批次建子目录：`archived/YYYYMM_主题/方案|验收报告/`）；被新版取代时旧版移入 `archived/` 并注明取代关系。
3. **对外资料**（说明/文案/海报）保留在根目录；生成脚本集中放在 `拼接说明_插图/`，改版时重跑脚本再导出。
4. **截图/辅助素材**：随对应文档一起归档或删除。
