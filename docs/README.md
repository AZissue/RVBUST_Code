## 三、维护规则

1. **审查报告**：只保留最新一轮在根目录；旧轮次报告直接删除（结论已并入新报告核验表），不积压归档。
2. **方案类文档**：实现并验证后，移入 `archived/`；被新版取代时旧版移入 `archived/` 并在归档表注明取代关系。
3. **重复/中间版本**：直接删除，只在根目录保留最新版。
4. **截图/辅助素材**：随对应文档一起归档或删除。
