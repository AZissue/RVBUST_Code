# 新版会话管理（1.12.7）

适用于三个 industrial 新版工作区；旧版保存入口保持原行为，已有会话支持导入。

## 新建与临时工作区

顶部“新建会话”输入工件/项目名称，DB 显示一个项目根节点，拍摄帧均在该项目下。
未新建时使用“未命名”草稿，进入界面不创建正式保存目录；拍摄的原始数据先写系统临时工作区，以便 SDK 释放后仍可读取。
临时工作区位于系统临时目录的 `MCC_workspaces/<随机ID>/`，与已保存项目隔离。
DB 数据与移动机位使用同一份原始 PLY/PNG；原始有序点云不下采样，识别及拼接仅更新元数据/工作流。

切换工作区保留各自草稿。新建或打开其他会话时如有未保存修改，提示保存、放弃或取消。
连接设备不会自动保存项目，也不会自动恢复上一次多相机外参；需要主动打开会话或加载外参。

## 保存与命名

点击保存，首次可选择是否包含原始帧：

| 功能 | 默认保存 | 包含原始帧选项 |
|---|---|---|
| 多相机 | 外参、参考相机、标定质量及设备描述 | 可包含标定/扫描点云和图像，尚无标定结果时默认勾选 |
| 多机位 | 点云、2D图像、识别、机位顺序、位姿、配准关系 | 始终包含，支持继续拼接 |
| 转台 | 转轴、中心、步进角度、步数 | 可包含标定帧及扫描序列，尚无标定结果时默认勾选 |

仅保存标定信息时，未选择的原始帧不会进入正式快照；需要离线复核/中断续扫应勾选原始帧。
保存根目录是程序项目根目录下 `sessions/`，与启动终端工作目录无关：

```text
sessions/
  移动拼接_工件名称_YYYYMMDD_HHMMSS_项目ID前8位/
    session.json             # 格式/版本、功能、单位、项目名称和工作流
    data/                    # 选择包含原始帧时存在
      index.json             # DB 索引和可恢复删除记录
      frames/<帧ID>/
        pointmap.ply
        image.png
      .trash/<删除批次>/<帧ID>/...
```

名称过滤 Windows 非法字符及保留名称，时间与 ID 避免重名。同一项目重复保存更新同一目录；需要另一个项目时先新建。
保存采用完整元数据快照和目录替换，失败保留旧快照；不可变原始文件在同卷支持硬链接时复用旧快照，不链接临时工作文件，不支持时复制。
读取草稿、继续拍摄、删除帧都不会提前改变已保存会话。保存期间需为新帧/复制回退预留磁盘空间，实际速度需要目标机测试。
“导出点云”单独选择 PLY 保存路径，同时生成误差报告；它不会自动保存会话，也不随放弃草稿清除。放在会话目录内的独立导出文件和附加说明在重复保存时保留。

## 载入与旧数据

“打开会话”选择包含 `session.json` 的项目目录，先检查格式、工作区类型和毫米单位，读取/校验失败保留当前会话。
多机位恢复保存的位姿及关系，不重新计算已保存配准；原始点云按需参与后续操作。
多相机只保存参数时可直接恢复外参；转台只保存参数时从新的扫描序列开始，包含序列时可继续处理。

旧多相机/转台会话目录以及旧 `station_*` 机位目录也可从同一入口选择，导入为新格式草稿。
旧机位数据需要按原流程重新检测/配准，再保存新格式。导入不会修改旧源目录。
DB 原始浏览索引与工作流快照不同；新入口统一按会话管理，不用 DB 索引代替完整会话载入。

## 关闭

关闭不会自动保存。所有工作区有未保存修改时统一列出：

- 保存：逐个保存，完成后关闭；失败或取消保存保持窗口。
- 放弃：关闭后清理本进程临时工作区，已保存快照保持不变。
- 取消：保留当前工作继续操作。

正常退出清理临时原始帧和离线预览副本；异常终止可能留下系统临时目录，不自动删除其他进程的临时工作区。

## 占用与清理

左侧“会话占用 / 管理”后台统计当前工作区、回收区、正式项目及历史 `offline_data`。
表格可多选删除已保存/历史会话目录，操作前确认；当前打开的正式会话，以及仍被各工作流引用的旧目录禁止删除。
“清空未引用回收区”永久删除当前工作区已丢弃且不再被标定/拼接使用的帧；保存后才同步到正式快照。
DB 删除仍是可恢复移除，不表示退出拼接；机位删除控制是否参与计算，两者独立。
历史目录不会自动清理，避免删除旧工程或其他用途的数据。项目数据已加入 Git 忽略规则。
