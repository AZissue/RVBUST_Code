# 无标记拼接的几何辅助

## 1.14.45 顺序选择

「识别参数 → 几何辅助与 ICP 精配准 → 执行顺序」提供「几何联合优化 → ICP」（默认）和「ICP → 几何联合优化」。两项同时开启时可选，单独开启一种算法时顺序不影响执行。该选择随会话保存，旧会话未记录顺序时使用默认值。

两种组合都先计算全部帧的 2D 特征/3D 初始位姿。ICP 放前面时，使用特征阶段的固定参考精修，再联合优化；放后面时，使用联合阶段的固定参考精修。两者使用相同的点到点 ICP 和验收检查，避免在对比顺序时额外切换 ICP 求解器。失败均保留前一阶段位姿，日志按实际执行顺序显示。以下关于固定顺序的历史说明以本节为准。

## 1.14.44 执行顺序

两项同时开启时，改为「2D 对应点初配准 → 多帧几何联合优化 → 末轮点到点 ICP」。界面将原「多尺度精修 + 多帧联合优化」明确命名为「多帧几何联合优化」。

末轮 ICP 使用联合阶段的固定参考位姿，每帧与此前最多三帧工件 ROI 的点云精修，不逐帧传播末轮 ICP 修正。除重叠率、局部几何改善及位移上限外，还检查原始特征对应约束、固定参考的双向几何误差。未通过时保留该帧联合阶段位姿，首帧始终固定。

只开联合优化时，保持原有的特征初配准和联合优化流程；只开 ICP 时，保持原有的逐帧点到点精修流程。采集仍只后台缓存 2D 匹配，所有 3D 阶段由手动执行拼接触发。新版顺序需与只开联合优化的结果对照，不能仅以 ICP 残差降低认定质量改善。以下旧版本顺序以本节为准。

识别参数中的「几何辅助与 ICP 精配准」在手动点击「执行拼接」后工作。采集期间仍只在后台缓存 2D 匹配，不自动运行几何配准或拼接。

## 1.14.42 修正

以 2D 对应像素映射的 3D 内点计算初值，几何仅负责局部微调，不再用 FPFH 重置初值。FPFH 入口已隐藏，旧会话保存的开关不再参与本流程。

必须设置工件 ROI 或匹配 ROI，否则跳过 ICP/联合几何，保留特征初值，不退回全幅点云。ROI 内再依据有效 3D 特征点的邻域和深度范围限制计算数据，减少框内背景参与。此筛选依赖特征正确性，并不等于完整工件分割。

ICP 结果和联合优化结果均检查原始特征对应：至少维持配置要求的内点比例，特征 RMS 增量不能超过容许预算（0.05 mm、初值 RMS 的 10%、最多 0.5 mm 的容差四分之一，取最大值）。局部精修位移还不能超过最大纠偏量与特征配准容差中的较小值。检查失败保留上一阶段位姿。几何近邻残差下降本身不再足以通过验收。

## 求解流程

1. SuperPoint + LightGlue 对应像素映射到有效深度，计算特征初始位姿。
2. 启用 ICP 与多尺度模式时，先做粗尺度点到点，再做细尺度稳健点到面 ICP。各尺度在同一组工件采样上评估，保留较好的候选，避免末轮覆盖较好的结果。
3. 启用多帧联合优化时，固定首帧，同时调整有几何重叠的帧。最近若干帧与可重叠的首尾帧共同提供约束；使用法线方向一致的互近邻和稳健损失，减少离群对应的影响。与首帧几何约束不连通的帧保留逐帧位姿。
4. 最终位姿应用于每帧全部有效原始点并写入来源变换。采样只用于计算，不删减输出点，也不覆盖原始文件。

几何使用工件 ROI；未设工件 ROI 时使用匹配 ROI。工件框应避开静止台面和背景。矩形框包含的背景仍会参与几何求解，二值化纹理增强掩膜不等于 3D 工件分割。

## 参数说明

| 参数 | 含义与起始设置 |
| --- | --- |
| 拼接时启用 ICP 优化 | 默认开启，逐帧精修到最近三帧的工件点云。 |
| 多尺度精修 + 多帧联合优化 | 默认开启。在原始特征约束内微调，同时检查几何误差、重叠率和修正量。关闭后使用点到点 ICP，仍执行特征检查。联合优化也可单独启用。 |
| 寻找相邻表面的范围 | 默认 2 mm，每次寻找对应点的距离上限。太大容易吸附错误表面。 |
| 允许纠偏的最大幅度 | 默认 5 mm，与搜索距离独立。逐帧精修还受特征配准容差上限限制，联合优化还必须通过原始特征检查。 |
| 计算采样间距 | 默认 0.5 mm；多尺度使用其 4、2、1 倍，细节较小可适当减小，计算会增加。 |
| 最多优化次数 | 默认 50，用于各尺度 ICP 和每轮联合求解。 |
| 最低工件重叠率 | 默认 30%；用于 ICP 结果及联合几何约束覆盖率检查。 |
| 联合优化采样间距 | 默认 1 mm，仅影响计算采样。 |
| 联合参考的相邻帧数 | 默认 3 帧，增大可增加重叠约束与计算量。 |
| 联合校正轮数 | 默认 3 轮，每轮重新寻找对应点并调整位姿。 |

先用默认参数复验；存在细小重影时，可对照 0.25–0.5 mm 的 ICP 采样和 0.5–1 mm 的联合采样。每次保持相同帧和 ROI，查看日志中的采用/拒绝原因以及固定采样残差。不要只通过放宽搜索距离、重叠门槛判断精度提高。

日志中的几何 RMS 是带搜索距离截断的近邻残差，底栏仍显示特征初值拟合误差，两者都不是实物测量精度。薄片正反面、对称外形、深度系统误差以及混入静止背景仍可能造成分层；最终需检查工件局部截面和多角度结果。几何采样或优化不可用时保留已有位姿并记录原因。
