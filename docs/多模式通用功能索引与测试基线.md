## 通用功能维护约束

1. 先定位职责：算法改 core，图像/渲染改 ui_common，跨模式动作与生命周期改 ui_v2 控制层，模式工作区只做必要适配。
2. 明确坐标与单位：外参 `T` 表示 cam→ref，`p_ref = T @ p_cam`，行向量写作 `pts_cam @ R.T + t`。SDK 内存点云与项目毫米制的转换必须显式处理；现有项目保存清单使用 `mm`。
3. 3D 提取依赖原图尺寸与有组织点云槽位顺序。`markers_all` 用于解释检测状态，算法配准只消费有效标记，不能把无深度标记补成原点。
4. 工业标记分类：绿=有效测量点；红=当前显式两帧共有/本次内点；黄=有2D无有效3D。classic 通用预览默认仍使用“绿有效/红无深度/蓝标定板”。应以实际呈现层为准，避免把旧注释当作统一协议。
5. 渲染降采样与业务滤波分开；清空/切会话立即清理 2D、3D、标记与异步请求。保存不能意外拿显示缓存替代原始数据。
6. 共用设备/检测器有可变状态。修改检测参数与采集并发时检查 SDK 锁、检测锁、线程池及关闭路径；本次不宣称全部 SDK 调用的锁覆盖已审计完成。
7. 新增通用 API 时核对 A/B/C、离线回放以及注入的 fake/mock 签名；正式回归不盲目根目录 pytest 收集。

| 编号 | 级别与状态 | 最小复现及影响 | 定位与建议 |
