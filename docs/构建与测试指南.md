# RvcVisionStudio 手动编译、启动与测试指南

> 适用环境：本机（Windows 11，VS Community 2026 + CMake 4.2.3）。
> 工程根目录：`D:\RVC_SRC\RvcVisionStudio`。以下命令均以 **CMD / PowerShell** 为准（Git Bash 下路径写法需相应调整）。

## 1. 编译自编译 VTK（仅首次或 VTK 目录缺失时需要）

主工程依赖带 Qt 支持的 VTK 9.2.2（PCL 自带的没有）。`third_party\VTK-install` 已存在且完整时**跳过本节**。

```bat
cd /d D:\RVC_SRC\RvcVisionStudio

:: 1) 配置（约 1-2 分钟）
cmake -S third_party/VTK-src -B third_party/VTK-build -G "Visual Studio 18 2026" -A x64 ^
  -DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=ON ^
  -DVTK_GROUP_ENABLE_Qt=YES -DVTK_QT_VERSION=6 ^
  -DCMAKE_PREFIX_PATH="D:/Qt/6.8.3/msvc2022_64" ^
  -DVTK_BUILD_TESTING=OFF -DVTK_BUILD_EXAMPLES=OFF ^
  -DCMAKE_POLICY_VERSION_MINIMUM=3.5 ^
  -DCMAKE_INSTALL_PREFIX=D:/RVC_SRC/RvcVisionStudio/third_party/VTK-install

:: 2) 编译（12 核约 33 分钟；机器拿去干别的会更久）
cmake --build third_party/VTK-build --config Release --parallel 12

:: 3) 安装到 third_party/VTK-install
cmake --install third_party/VTK-build --config Release
```

验证：`third_party\VTK-install\bin` 下应有约 147 个 `vtk*-9.2.dll`，其中包含 `vtkGUISupportQt-9.2.dll`。

> 注意：CMake 4.x 配置时必须带 `-DCMAKE_POLICY_VERSION_MINIMUM=3.5`；若删除了 `VTK-src` 重新 clone，需要重打 README 里说明的 diy2/fmt 补丁。

## 2. 编译主工程

```bat
cd /d D:\RVC_SRC\RvcVisionStudio

:: 1) 配置
cmake -B build -G "Visual Studio 18 2026" -A x64 -DCMAKE_PREFIX_PATH="D:/Qt/6.8.3/msvc2022_64"

:: 2) 编译 Release（增量编译只重编改动部分，通常 1-3 分钟）
cmake --build build --config Release
```

成功标志：`build\Release\` 下生成 `RvcVisionStudio.exe`、`unit_tests.exe`、`QtNodes.dll` 及约 270 个运行时 DLL（构建后自动拷贝：RVC runtime、自编译 VTK、PCL/OpenNI2、Qt）。

可选配置项：

- `-DRVC_SDK_ROOT=<路径>`：RVC SDK 不在默认位置时指定
- `-DRVC_TEST_PLY=<PLY 路径>`：替换单测用的真实点云文件（默认 `D:\Kimi_WorkSpace\Test\captured_data\offline_visualize.ply`）

**日常改动代码后**：只需重复第 2 步 `cmake --build build --config Release`。新增了源文件（CMakeLists 改动）时重复第 1+2 步。

**用 IDE 开发（可选）**：

- Visual Studio（方式一，打开解决方案）：直接打开 `build\RvcVisionStudio.slnx`，把 `RvcVisionStudio` 设为启动项目，配置选 `Release x64`
- Visual Studio（方式二，打开文件夹 / CMake 模式）：「打开本地文件夹」选工程根目录。
  工程自带 `CMakePresets.json`（已固化 Qt 路径与 cl 编译器），在顶部配置下拉框选
  **x64-Release** 或 **x64-RelWithDebInfo**，然后「生成 → 全部生成」；产物在
  `out\build\<配置名>\`（与命令行的 `build\` 互不干扰）。启动项选 `RvcVisionStudio.exe` 即可 F5 调试。
  注意：①不要选 x64-Debug（运行时 DLL 只部署了 Release 系）；②本机 PATH 里有 msys64 的
  gcc，preset 已固定 `cl.exe` 防止 CMake 误抢（误抢会导致 PCLConfig 报
  "PCL can not be found"，并非 PCL 安装问题）；③改过 preset 或缓存异常时，用
  「项目 → 删除缓存并重新配置」
- Qt Creator：打开工程根目录的 `CMakeLists.txt`，Kit 选 Qt 6.8.3 MSVC2022

## 3. 自动化测试

### 3.1 单元测试（Catch2，22 用例）

```bat
cd /d D:\RVC_SRC\RvcVisionStudio\build
ctest -C Release --output-on-failure
```

期望输出末尾：`100% tests passed, 0 tests failed out of 22`。
也可以直接跑测试程序看断言细节：`Release\unit_tests.exe`（加 `-s` 显示成功断言，加 `"用例名"` 只跑单个）。

### 3.2 无头回归测试（不开 GUI）

```bat
cd /d D:\RVC_SRC\RvcVisionStudio

:: M0 链路回归：加载 PLY → 3D显示回调，退出码 0 = 通过
build\Release\RvcVisionStudio.exe --selftest "D:\Kimi_WorkSpace\Test\captured_data\offline_visualize.ply"
echo %ERRORLEVEL%

:: 测量流水线冒烟：加载 → ROI → 降采样 → 平面拟合 → 点面距，退出码 0 = 通过
build\Release\RvcVisionStudio.exe --smoke "D:\Kimi_WorkSpace\Test\captured_data\offline_visualize.ply"
echo %ERRORLEVEL%
```

smoke 的通过判据：点面距均值 < 5 mm（当前实测约 0.7 mm）。

### 3.3 GUI 冒烟（自动演示 + 定时退出）

```bat
:: 自动搭建演示流水线并运行，10 秒后自动退出；退出码 0 = 正常
build\Release\RvcVisionStudio.exe --demo "D:\Kimi_WorkSpace\Test\captured_data\offline_visualize.ply" --autoquit 10
echo %ERRORLEVEL%
```

## 4. 手动启动与功能测试清单

```bat
build\Release\RvcVisionStudio.exe
```

启动后按以下清单逐项验证（对应各里程碑功能）：

### 基础链路（M0）
1. 左侧工具箱顶部搜索框输入「PLY」快速定位；展开「采集」分类把 **加载PLY点云** 拖入画布；
  「显示」分类拖入 **3D显示**
2. 选中「加载PLY点云」节点 → 右侧「属性」面板点 `...` 选 PLY 文件（如 `D:\Kimi_WorkSpace\Test\captured_data\offline_visualize.ply`）
3. 从 `cloud` 输出端口拖线到「3D显示」的 `cloud` 输入端口
4. 工具栏点 **运行** → 右侧视窗出点云，日志栏显示各模块耗时

### 测量流水线（M2）
5. 再拖入：ROI裁剪 → 体素降采样 → 平面拟合 → 点面距离，按数据流向连线（cloud 串起来，平面拟合的 `plane` 接到点面距离的 `plane`）
6. 平面拟合的 `plane` 同时接到「3D显示」的 `plane` 可选端口 → 视窗出现黄色平面网格叠加
7. 运行后切到底部「结果」tab，查看 mean/max 数值

### 交互式视窗（M3）
8. 视窗内：左键旋转、右键缩放、中键平移；工具条「重置视角」复位；「点大小」调节
9. **框选 ROI**：先在画布上点选「ROI裁剪」节点 → 点视窗工具条「框选ROI」→ 在点云上拖矩形 → 框内区域包围盒自动写入该节点的 xmin..zmax 参数，并显示绿色线框；再运行，点数应明显减少
10. ROI 连线订阅：把「ROI裁剪」的 `roi` 输出连到「平面拟合」的 `roi` 输入 → 平面拟合只在内点区域拟合；断开该连线、改在属性面板勾 `roiEnabled` 手填 roiXxx，效果相同（连线优先）

### ROI 设置弹窗（M4）
11. 运行一次流程让主视窗加载点云；选中「平面拟合」节点 → 属性面板底部点「设置 ROI…」
12. 弹窗中选择「2D 矩形（XY 平面）」：
    - 空白处拖拽画新矩形；
    - 矩形内部拖拽移动位置；
    - 拖边缘或角调整大小；
    - 滚轮缩放视图、右键拖拽平移视图；
    - 底部参数实时更新，z 参数禁用为 ±1e9
13. 选择「3D 盒体」：内嵌 3D 视窗自动显示 box widget → 拖 7 个 handle（6 面 + 中心）调整大小，
    或中键/右键整体调整 → 6 个参数实时同步
14. 点「确定」→ 属性面板 `roiEnabled` 自动勾选、`roiIs2D` 按模式写入；再运行流程，拟合应只在 ROI 内生效

### 多视窗（M3）
15. 「窗口」菜单 → **添加3D视窗** → 出现「视窗2」
16. 再拖一个「3D显示」节点，属性面板把 `viewport` 改成 `视窗2`，接另一路点云（如降采样前）→ 两个视窗各显示各的
17. 「窗口」菜单勾掉某个 Dock 即折叠隐藏，勾上恢复；Dock 标题栏可拖到别的停靠区

### 方案保存/加载（M2）
18. 工具栏「保存方案」存 JSON；关闭程序重开，「打开方案」恢复模块/连线/参数/节点位置，直接可运行

### UI 布局与主题（M4）
19. 顶部为暗色自定义标题栏（无系统白边），与整体暗色主题一致；双击标题栏最大化/还原，
  拖动标题栏移动窗口，边缘 8px 可缩放
20. 左侧工具箱可点击分类箭头折叠/展开；顶部搜索框支持实时过滤模块；`Ctrl+F` 快速聚焦搜索框

### 异步执行（M3）
21. 运行期间「运行」按钮变灰禁用，日志逐条推送，结束打印总耗时（界面不卡）

## 5. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 配置时报找不到 VTK | 先完成第 1 节 VTK 编译；确认 `third_party\VTK-install\lib\cmake\vtk-9.2` 存在 |
| 配置时报找不到 Qt6 | `-DCMAKE_PREFIX_PATH` 必须指向 `D:/Qt/6.8.3/msvc2022_64`（不是 `D:\Qt`） |
| exe 启动报缺 DLL | 重新执行第 2 步构建（POST_BUILD 会补拷）；不要用 Debug 配置（依赖只部署了 Release） |
| 视窗黑屏/花屏 | 显卡驱动问题居多（本机 Quadro P620 验证正常）；确认没有误删 `QSurfaceFormat` 初始化（main.cpp） |
| 文件对话框一闪而过 | M0 已修（alien widget 无 HWND）；若复现说明改动被回退，查 `PropertyPanel.cpp` 对话框父窗口 |
| 拟合失败「内点过少」 | 先用 ROI 把目标区域箍紧；适当调大 `distanceThreshold` |
| 单测个别拟合用例偶发失败 | RANSAC 是随机的，重跑一次；持续失败才是回归 |
| Git Bash 下 `--parallel` 参数异常 | 在 Git Bash 执行 cmake --build 时管道/斜杠参数可能被转换，建议用 CMD |
