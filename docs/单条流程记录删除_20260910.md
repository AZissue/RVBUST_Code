# 单条流程记录删除

工单详情的处理时间线中，每条记录右侧新增删除图标，仅管理员显示并可操作。

## 操作

1. 点击需要清理记录右侧的删除图标。
2. 检查记录内容并填写删除原因。
3. 点击确认删除记录。取消或关闭弹窗不会删除。

## 规则

- 仅隐藏选中的时间线记录，不删除整张工单。
- 不改变工单当前状态、负责人、协助邀请、附件或工作记录。
- 删除状态变更记录不会回退状态，删除邀请记录不会撤销邀请；这些业务操作仍需通过原有控件完成。
- 原始记录保留，操作日志记录删除人、时间、原因及原内容。
- 服务端验证管理员权限和工单归属，重复删除返回冲突。
- 不新增数据库迁移，不删除原始附件文件。
