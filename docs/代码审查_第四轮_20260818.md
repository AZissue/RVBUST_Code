### 3.2 新 P1：级联重配准产生重复边 → BA 双权重 + 误差报告重复

- **位置**：`chain_stitcher.py:320-350`
- **证据**（repro_core_audit5b.py 实测）：重配准循环内 `reachable.add(sid)` 只加单节点、不做 BFS 闭包扩展；下游节点 s4 已"事实上连通"但判断为 False → 对 s3 重复 `_try_register` → 追加重复边。实测输出：
  ```
  edges after: [('s4','s3'), ('s3','s1'), ('s4','s3')]   # (s4,s3) 两条
  邻接表 s3 的邻居: ['s4','s1','s4']
  ```

  几何/T_world 仍正确（图连通、继续拍摄正常），但 `self.edges` 与 `pose_graph._adjacency` 双份 → **BA 残差把该约束计两遍（权重翻倍）、get_error_report/get_station_evaluations 重复列边**。
