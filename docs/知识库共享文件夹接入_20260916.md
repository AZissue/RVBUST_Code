# CRM 知识库接入共享文件夹 — 改造方案（修订版 v2）

> 编制日期：2026-09-16
> **v2 修订说明**：取消「网页上传」功能；权限模型改为**全员只读 + 管理员可编辑内容/删除**；知识库内容维护与整理以文件系统操作（Elara 侧）为主。
> 目标：把当前独立的文件共享服务（浏览/下载/预览）迁移进 CRM 知识库板块，统一走 CRM 登录鉴权
> 实施方式：本方案仅为设计说明，由开发同事在本地实现后推送 GitHub，服务器侧按部署流程更新（不在服务器直接改代码）
> 本期范围：**浏览目录、下载、预览、管理员编辑文本内容、管理员删除**

## 二、权限模型（本期核心变更）

| 角色 | 浏览 | 预览 | 下载 | 编辑文本内容 | 删除 | 新建/重命名 |
|---|---|---|---|---|---|---|
| admin（管理员） | ✓ | ✓ | ✓ | ✓ | ✓（移入 `.trash`） | ✓（可选） |
| support / employee | ✓ | ✓ | ✓ | ✗ | ✗ | ✗ |
| customer（客户） | ✗ | ✗ | ✗ | ✗ | ✗ | ✗ |

实现方式：控制器级 `@Roles('admin','support','employee')` 提供读权限；写类接口（编辑/删除/新建/重命名）单个方法上加 `@Roles('admin')` 覆盖。

**内容维护方式（重要）**：网页端**不提供上传**。知识库文件的增删改由维护方直接在文件系统操作（Elara 侧按目录规范整理、批量更新手册与文档），网页端只作为「浏览 + 预览 + 管理员小修小补」的入口。

## 三、技术路线：文件系统直通

知识库根目录由环境变量指定，后端直接读写该目录；**不建数据库表**，目录结构本身就是数据源。

- 优点：改动最小、无需数据迁移（根目录指向现有共享目录即可，零拷贝）、与现有投递方式（scp/rsync）完全兼容、大文件下载走流式不占内存
- 代价：无版本历史（用 `.trash` + `.history` 兜底）、无文件级细粒度权限（按角色粗分）
- 本期不做 DB 索引方案；等出现"按客户/机型检索、记录谁改了什么"的需求再升级

```
KB_ROOT=/home/gene/shared     # 知识库根目录（可随时改指向，无需改代码）
```

### 4.3 API 接口清单

统一前缀 `/api/kb`，全部要求已登录。

| 方法 | 路径 | 角色 | 说明 |
|---|---|---|---|
| GET | `/api/kb/list?path=<相对路径>` | 全员 | 列目录：条目名、类型、大小、修改时间、是否可预览、是否可编辑；返回面包屑与父路径 |
| GET | `/api/kb/download?path=<相对路径>` | 全员 | 下载（`Content-Disposition: attachment`，文件名 RFC 5987 编码） |
| GET | `/api/kb/preview?path=<相对路径>` | 全员 | 内联预览（图片/PDF/文本/视频/音频） |
| GET | `/api/kb/content?path=<相对路径>` | 全员 | 读取文本文件原文（供编辑框加载，返回纯文本 + 大小 + 是否为可编辑类型） |
| PUT | `/api/kb/content` | **admin** | 保存文本内容（body：`path` + `content`）；保存前把原文件备份到 `.history` |
| POST | `/api/kb/delete` | **admin** | 删除（默认移入 `.trash`，不物理删除） |
| POST | `/api/kb/mkdir` | **admin**（可选） | 新建文件夹（body：`path` 父路径 + `name`） |
| POST | `/api/kb/rename` | **admin**（可选） | 重命名/移动（body：`path` + `newName`） |

> **已移除**：上传接口（`POST /api/kb/upload`）。因取消网页上传，原本需要放开的 nginx `client_max_body_size`、以及 Cloudflare 免费套餐 100 MB 单请求上限的顾虑**均不再存在**（写入内容走 JSON 请求体，几百 KB 级即可）。

> 路径用**查询参数**传递而非 URL 路径段，避免中文/空格文件名的编码问题，也绕开 nginx 对路径的归一化处理。

### 4.4 安全设计（本模块最关键部分，务必按此实现）

**a) 路径穿越防护**——所有请求路径必须经过统一校验函数：

```ts
function safeResolve(root: string, userPath: string): string {
  const abs = path.resolve(root, userPath || '.');
  const rel = path.relative(root, abs);
  if (rel.startsWith('..') || path.isAbsolute(rel)) throw new ForbiddenException('非法路径');
  // 防符号链接逃逸：对真实路径再校验一次
  const real = fs.realpathSync(abs);
  const relReal = path.relative(fs.realpathSync(root), real);
  if (relReal.startsWith('..') || path.isAbsolute(relReal)) throw new ForbiddenException('非法路径');
  return real;
}
```
必须同时做**解析后校验**与 **realpath 校验**，只做前者可被符号链接绕过。

**b) 预览/可编辑类型白名单**：

| 类型 | 扩展名 | 渲染方式 | 可否网页编辑 |
|---|---|---|---|
| 图片 | jpg/jpeg/png/webp/gif/bmp | `<img>` | ✗ |
| PDF | pdf | `<iframe>` | ✗ |
| 文本/代码 | txt/md/log/json/yaml/yml/csv/ini/conf/py/ts/js/sh/c/cpp/java | `<pre>` 纯文本 | ✓（≤ KB_EDIT_MAX_KB） |
| 视频 | mp4/webm/mov | `<video controls>` | ✗ |
| 音频 | mp3/wav/m4a | `<audio controls>` | ✗ |
| 其他（含 html/svg/zip/office） | — | 不预览，仅下载 | ✗ |

**html / svg 必须按纯文本或下载处理，绝不能内联渲染**（XSS 风险）。所有响应固定带 `X-Content-Type-Options: nosniff` 与 `Cache-Control: private, no-store`。

**c) 保存内容的安全要点**：
- 仅允许白名单内的文本扩展名保存；**禁止通过"保存"绕过扩展名限制创建可执行/可渲染文件**（如 `.html`、`.svg`）；
- 大小校验：超过 `KB_EDIT_MAX_KB` 拒绝；
- **原子写入**：先写临时文件再 `rename` 覆盖，避免写一半中断造成文件损坏；
- **写前备份**：原文件复制到 `.history/<原相对路径>/<时间戳>`，管理员误改可恢复；
- 保存后立即失效前端缓存（前端带 `no-store`，无需额外处理）。

**d) 大文件处理**：
- 下载用 `res.sendFile(...)`（Express 流式 + 支持 Range 请求，视频拖动进度条依赖它），不要用 `readFile` 读进内存（135 MB 文件会占满内存）
- 预览视频/音频同样走 `sendFile`

**e) 并发写**：本期不做文件锁；同名同时保存为"后写覆盖先写"，依赖 `.history` 兜底。

### 4.5 权限与审计

- 读接口：控制器级 `@Roles('admin','support','employee')`；客户角色访问返回 403
- 写接口：方法级 `@Roles('admin')`
- 全局 `AuditInterceptor` 已自动记录写操作（PUT/POST/DELETE），无需额外代码
- 可选：在 `permissions` 表增加 `knowledge.read` / `knowledge.manage` 权限码（现有角色权限体系已支持），本期用 `@Roles` 已足够

## 九、风险与限制（本期已知）

1. **无网页上传**：新增文件只能由维护方在文件系统投递（这是本期的设计选择，同时规避了 Cloudflare 100 MB 单请求限制）
2. **无版本历史**：覆盖与删除依赖 `.history` / `.trash` 目录兜底，无正式版本管理；如需要，建议后续把知识库目录纳入 git 管理
3. **无文件级权限**：知识库对全体内部成员可见（admin/support/employee 一视同仁），如需按客户/项目隔离需升级到 DB 索引方案
4. **网页编辑范围有限**：仅白名单文本类文件且 ≤512 KB（可配），手册类 PDF 与二进制文件仍需文件系统操作
5. **磁盘空间**：共享目录现 214 MB，本机可用约 45 GB；`.history` 会随编辑累积，建议后续加定期清理或容量监控
6. **原 Flask 服务停用时机**：需确认团队已全部切到 CRM 入口后再停，避免有人仍收藏了 5000 端口地址
