# UIv2 扩展与旧 UI 弃用检查

日期：2026-10-18。范围：正式入口、UIv2、公共组件、原型、工具、测试和打包配置。

## 结论

当前装配层支持后续重新设计主题、图标、2D/3D 组件、启动器、主窗口和 A/B/C 工作区。新设计必须保持公开信号、结果回填与生命周期接口；并非任意 QWidget 无适配替换。

旧 `src/ui` 已删除，包含历史 MainWindow、面板、向导、工作流视图及兼容转发。公共渲染器和线程是仍需维护的基础组件，不再依赖旧窗口。VTK 实验渲染器移至 `ui_common/vtk_viewer.py`，其 API 尚不完整实现 PointCloudView，不能直接作为主渲染器注入。

## 替换能力与边界

| 设计目标 | 当前入口 | 边界 |
|---|---|---|
| 主题、图标 | UiComposition.stylesheet / icons；公共组件 appearance | 局部控件仍有内联颜色，任意 QSS 不保证覆盖全部视觉；完整视觉重做需同步调整组件 |
| 2D/3D 组件 | UiComponents | 必须是 Qt 控件且实现 ImagePreview / PointCloudView 协议；协议检查不等于签名、性能验收 |
| 工作区布局 | WorkspaceFactories | 保留公开信号、结果方法和主窗口所用状态接口；A 仍公开 camera_grid，B 公开 live_view |
| 主窗口、启动器 | UiComposition.shell_factory / launcher_factory | 保留设备选择、连接遮罩、保存和关闭等待契约 |
| 转台整体重写 | turntable 工厂 | 现有工作区同时持有 session、标定和采集逻辑；BackendBridge 保存会话读取其 session，须保留模型适配或先抽取业务层 |
| 新增业务模式 | 显式扩展模式与工作流 | 当前不是自动发现的通用插件系统 |

因此后续布局与视觉设计可以推进。若目标是独立技术栈界面或完全无业务逻辑的视图，仍需要进一步抽取转台控制器、完整工作区协议及网格/取景适配器。

## 回归迁移

- `test_ui.py`：UIv2 架构回归入口，不再实例化历史主窗口。
- `test_integration.py`：保留三相机、五帧合成场景、落盘重载、检测回写、多帧外参、3000 点拼接和矩阵保存加载验证；直接测试离线核心服务。历史窗口按钮断言已退役，这不是完整实机 UI 端到端验证。
- `test_station.py`：站位持久化、内容不被覆盖、删除与新会话保留历史目录，以及 UIv2 时间线映射。
- `test_ui_architecture.py`：禁止仓库 Python 源码导入旧 UI；隔离进程拦截旧包后创建 A/B/C；预览/渲染器替换、主题图标、动作接线、离线回填与线程生命周期。

## 本次验证

17 项架构测试通过；离线集成、站位、工作流和标记绘制脚本退出码均为 0。三相机离线拼接为 3000 点，合成场景平均对齐误差约 0.29 / 0.14 mm，仅代表该合成数据回归。

未进行相机连接采集、真实显示/GPU 性能测试、VTK 对比窗口运行或 PyInstaller 完整构建。上述结果验证扩展接口与离线行为，不代表大型点云帧率或实机精度保证。
