# 公共2D/3D视图（v1.13.60）

四种industrial工作区使用 `src/ui_common/multimodal_viewport.py` 中的 MultimodalViewport。3D和2D是同一帧的不同视图；控件只管理页签、叠加布局和数据来源标识，不拥有SDK、不重新创建渲染器。各模式提供现有3D ViewerPanel与2D检查器/相机网格，共享业务数据和后台采集流程。

- 默认3D点云；2D图像页占用完整可用区域；对照使用完整3D画布，2D小窗叠加在右上角并随窗口尺寸定位。
- 点击DB点云项进入3D、图像项进入2D；目录项与可见性勾选保持当前页面。
- 进入实时取景切到2D，后续图像到达保持用户选定页面。每个工作区保留独立视图选择。
- 切页不重新加载点云，不重置3D相机；单相机2D图像滚轮缩放、左键平移、双击适配。
- 多相机沿用网格、全部预览/停止、单相机聚焦等动作；单相机图像保留标记颜色、统计和明细。
- 当前帧/实时/DB来源标识随数据切换，不以隐藏页面停止采集；停止采集仍使用原业务动作。

旧classic容器仍保留用于共享动作兼容与回归，但不提供用户入口。2D检查器增加embedded布局，3D标记投影仍绑定实际渲染器的canvas，图像面板不再跟随canvas右上角定位。后处理的纯点云工具和独立实验窗口不受此页签改动影响。
