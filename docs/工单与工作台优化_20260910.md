# 工单与工作台优化

## 已完成

- 工单增加我负责的、我协助的、待我接受、我创建的筛选，条件保留在网址中。
- 我的工作指标不再随当前状态筛选错误归零。
- 工作台增加待我接受入口；今日待办、今日完成入口与后台统计使用相同日期及负责人条件。
