# 多相机联合标定设计

用户只指定最终参考相机。所有拥有可靠共视编码圆的相机建立配对约束，不再区分星型和链式；不要求按相机编号相邻。点云单位为 mm，源点云始终保留相机局部坐标。

先使用逐对 RANSAC 与既有 RMS/内点率门禁筛选测量边，再用合格连接树初始化每台相机到参考系的刚体位姿。参考位姿固定为单位矩阵，联合最小化所有边的原始三维内点在参考系中的差异，使用稳健损失，包含交叉边与闭环。优化后所有变换查询从统一节点位姿计算，保证路径一致；测量边保留原始逐对误差，不冒充全局误差。

缺失连接必须阻止标定通过。异常、非刚体、非有限、无收敛或代价恶化的优化不得采用；可回退初始化，但必须明确说明且全部共视约束仍通过统一坐标残差门禁。优化后的约束矛盾阻止发布合格结果，不静默舍弃高残差边或只选一棵树掩盖矛盾。

外参保存每个节点到参考系的最终位姿、全部局部测量边和优化报告。载入检查刚体、参考锚点、节点完整性及测量约束一致性。旧 star/chain 会话和外参仍可读取并沿旧测量路径恢复；重新计算统一使用新算法。显式保存规则不变，不覆盖用户已有会话。

UI 入口统一为「联合标定设置」，仅设置参考相机与拍摄时序；结果显示参与约束、初始化路径、优化是否采用及全局三维残差。不能承诺噪声和误检条件下的绝对最优或真实测量精度。
