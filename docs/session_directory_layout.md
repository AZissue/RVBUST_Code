# 会话目录命名（v1.13.42）

显式保存后，正式会话的 `data/frames/` 使用以下目录命名：

`类型_分类编号_相机_YYYYMMDDhhmmss_短ID`

类型包括标定帧、拼接帧（扫描原始数据）、拼接结果、后处理结果。分类编号从001开始；创建时间来自原始记录，重拍保留原始排序。短ID用于区分同名数据，完整ID仍在索引中，内部来源关系不变。目录中保留 `pointmap.ply` 和原始帧的 `image.png`。

`data/数据清单.csv` 使用UTF-8 BOM编码，可用Excel打开，列出类型、分类编号、采集编号、相机、名称、创建时间、数据版本、状态、唯一ID、相对目录及来源ID。回收区仍由 `.trash` 管理，不混入当前有效帧清单。

通过主程序“打开会话”载入整个会话目录。读取时只在私有副本恢复内部UUID路径，正式快照保持不变。旧会话可以直接读取，再次保存时转换；不用手动改目录名或索引。正式快照中的data/index.json不能当作独立DB索引直接打开。旧版本程序不理解新布局，请使用新版读取。

保存操作仍先写暂存快照再原子替换，保留显式导出及用户附加文件；转换失败不替换旧快照。程序不会在启动、退出时批量迁移已有会话。


## 保存时命名（v1.13.54）

点击顶部“保存会话”时，弹窗提供“会话名称”，默认填入当前名称。启动后直接采集的未命名工作区也可在此命名。已有会话修改名称后保存，会同步更新会话列表、DB项目标题和磁盘会话目录，同时保留相同会话ID及全部数据。继续用相同名称保存则更新当前目录。

弹窗显示规范化名称，空名称不可保存。取消或保存失败保留旧名称、旧目录和数据；改名成功后使用新的保存位置打开会话。关闭/切换工作区流程保存已经保存过的会话时沿用名称，首次保存仍允许输入名称。
