# 主程序内的实验功能验证

入口：启动 MCC 新版主工作区，点击右上角“实验功能”。无需单独运行 prototypes 脚本。

## 第一版范围

| 功能 | 数据来源与操作 |
|---|---|
| 颜色统一、原色对比、原始2D融合 | 复制当前模式全部DB和工作流，打开正式后处理界面的颜色验证能力；优先载入当前勾选或选中的点云，无选择时选择最新顶层结果 |
| 几何后处理、框选、下采样、ICP | 复制当前模式，复用正式后处理界面和结果分支机制 |
| 固定多相机外参和拼接 | 复制多相机工作区，复用正式标定、拓扑选择和拼接流程 |
| 离线链式拼接 | 复制移动拼接工作区，复用正式离线导入、识别、入链与拼接流程 |
| 机器人手眼变换和戳点验证 | 复制机器人工作区，复用正式矩阵、位姿、戳点门禁及发布流程 |

原型已具备正式对应工作流的功能不再另建UI或引入独立原型应用。双目重建和并发采集压力测试本版未集成，仍是专项实验。颜色算法未在普通后处理中重新开放。

## 试用步骤

1. 打开需要测试的会话。颜色验证建议选择有完整原始图像、点云和最终位姿的拼接结果；仅导入普通PLY也能测试颜色统一，但不能凭空补齐2D融合来源。
2. 在DB勾选或选中目标点云，点击右上角“实验功能”，选择对应项目。
3. 复制在后台执行，包含尚未保存的数据；不会先保存或覆盖当前会话。出现“实验验证副本”横幅后按主程序相同操作测试。颜色和几何项目自动打开后处理窗口。
4. 关闭后处理窗口后，可在副本主窗口点击“保存会话”，保存到项目根目录 `outputs/experiments/`。关闭副本后返回原工作区，未保存修改沿用正式保存/放弃/取消提示。
5. 验证窗口内再次打开已有会话也重新建立验证保存身份，不回写打开的源目录。验证结果不会自动合并回主工作区；需要保留时显式保存或导出。

第一版只做离线验证：不继承主窗口设备连接，不自动初始化SDK、采集或后台识别；设备管理和参数调试在副本内不连接硬件。实机采集在主工作区执行后再创建新副本。副本存活时父窗口保持模态锁定，避免两边同时改动；同一时间只打开一个验证副本。

## 验收重点

- 颜色：曝光接缝、偏色、真实纹理、原色切换、来源完整性、保存重开、大数据性能。无几何预降采样时核对点数和XYZ不变；主动设置体素预降采样时按参数预期核对变化。
- 几何：框内/框外结果、撤销、来源保留、ICP失败恢复、显隐和导出。
- 业务工作区：标记物编号与变换方向、单位、入链失败提示、机器人戳点导出门禁。
- 共享生命周期：忙碌门禁、重复入口、保存取消、关闭返回、源会话文件及内存记录不变。

离屏回归命令（使用本机rvc解释器）：

```powershell
$env:QT_QPA_PLATFORM='offscreen'
$env:PYTHONIOENCODING='utf-8'
& 'D:/Program Files/Anaconda/envs/rvc/python.exe' -m unittest test_experiments test_color_postprocess test_postprocess test_session_projects -v
```

离屏测试不替代现场颜色效果、真实标定精度、原生GPU、大点云性能或客户机打包验收。
