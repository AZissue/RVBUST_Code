# MCC 离线实验项目

各项目复用主程序的工业工作区、DB 树和点云视图。使用本机 rvc Python，从 MCC 仓库根目录运行对应脚本。

| 项目 | 脚本 | 输入 |
|---|---|---|
| 颜色统一、原色对比、2D 融合、框内颜色过滤 | `prototypes/color_postprocess/run.py` | 有色点云会话。2D 融合还需要原始图像、有序点云及来源位姿 |
| FPFH 几何匹配 | `prototypes/fpfh_geometry_match/run.py` | 包含待配准点云的会话 |
| 几何后处理 | `prototypes/industrial_pointcloud_postprocess/offline.py` | 点云会话，可在后处理中补充导入 PLY |
| 普通圆点三角形匹配 | `prototypes/circle_geometry_match/run.py` | 至少两帧原始图像和对应的有序点云 |
| 固定多相机外参与拼接 | `prototypes/fixed_multi_camera/run.py` | 固定多相机会话 |
| 机器人手眼变换与戳点验证 | `prototypes/robot_handeye_transform/run.py` | 含手眼矩阵的机器人会话，未使用的原始帧可供离线变换 |

启动时选择已保存会话的 `session.json`，也可通过命令直接加载：

```powershell
& 'D:/Program Files/Anaconda/envs/rvc/python.exe' prototypes/color_postprocess/run.py --session 'D:/path/to/saved-session'
```

实验从磁盘加载私有副本。正式工作区中的未保存数据需先保存为会话。关闭后处理窗口后，在实验工作区点击“保存会话”，默认保存到 `outputs/experiments/<项目目录名>/`。可通过 `--output` 指定目录。每次打开源会话都会生成独立保存身份。主程序的“离线拼接”入口仍可直接加载 PNG/PLY 文件对。

## 框内颜色过滤：去除每帧黑边（1.13.57）

在颜色后处理原型中选择有原始RGB颜色的点云，点击“多边形框选”，围住需要清理的边缘，右键封闭。视口上方分割工具栏新增“颜色过滤”，无需执行原来的“快捷删除”。

- 默认过滤依据为亮度 `max(R,G,B)`，保留范围 `[40,255]`；框内低于40的暗点会被剔除。根据实际颜色逐步提高下限，例如60、80；不能保证这些数值适用于所有工件。
- 可切换加权灰度或单个R/G/B通道，也可降低上限排除高亮点。上下限都包含在保留范围内；过滤使用原始RGB，不使用高度着色或统一颜色显示值。
- 预览默认把待剔除点标红，取消“标红”查看去除后的效果。预览最多采样12,000点，统计及实际过滤基于全部原始点。
- 只筛选框内，框外全部保留。确认后生成“颜色过滤保留”和“阈值剔除”两个DB分支，仅显示保留结果；源数据保留，可以撤销、单独显示剔除分支或重新调整后处理。取消不生成结果。
- 框选沿视线投影，包含遮挡点。真实暗色纹理与黑边可能具有相同RGB，最好用窄框沿边缘分段清理。若黑边来自缺失或错误几何，颜色阈值只能删除点，不能补洞或恢复深度。
- 对重叠多帧，建议先“提取中间帧”，选择已对齐来源帧逐帧过滤，再勾选过滤后的保留分支合并；不要把源帧、剔除分支也一并勾选合并。当前过滤仅作用于当前选中的一项点云。

颜色后处理原型提供该入口。保存和导出遵守原有会话规则；含新颜色输出角色的验证会话应使用1.13.57及之后版本打开。

## 普通圆点三角形匹配（1.13.58）

启动普通圆点三角形匹配原型，点击“圆点匹配”。在隔离副本中选择参考/移动两帧原始DB数据，调整黑/白圆点和半径范围，点击识别，检查两侧对应编号、三角连线、边长及3D残差；核对确认后生成独立拼接结果。也可从实验副本后处理顶部“圆点匹配”重开。

输入为原始2D图像和同分辨率、逐像素有序、毫米点云，不能用无序PLY或拼接结果代替。至少3个不共线圆心，建议4个以上不对称共同圆点。存在同等可信的多解时拒绝拼接；本版不自动ICP，算法按三维边长匹配、不拟合尺度、不依赖2D点序。多边形匹配仅预留接口。

详细步骤、参数、限制与算法扩展契约见 `prototypes/circle_geometry_match/README.md`。现场识别率和精度尚未验收。
