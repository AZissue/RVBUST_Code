# 离线拼接正式功能（1.14.0）

## 进入与数据

启动小窗点击“离线拼接 · 本地文件”，或在主工作区顶部点击“离线拼接”。也可使用：

```powershell
& 'D:/Program Files/Anaconda/envs/rvc/python.exe' main.py --offline-stitch
```

独立正式离线窗口沿用industrial界面、DB树、2D/3D、识别参数、导出及后处理，不连接设备。主工作区已有数据和未保存内容保留；同一主窗口重复打开会激活已有离线窗口。关闭主窗口前也会处理离线窗口的未保存内容。

点击“加载数据目录”。同目录同名PNG/JPG/JPEG/BMP和PLY配对，兼容 `_color/_rgb/_depth/_cloud` 等后缀，按数字编号排序；歧义候选拒绝加载。可关闭“递归扫描子目录”。没有匹配文件时报告失败；单对损坏或分辨率不一致时列出原因，其他有效文件仍进入DB。

点云单位为毫米，必须是与图像逐像素对应的row-major有序点云；点数等于图像像素数仅是必要条件。输入为米时应先显式转换；本入口不自动猜单位，也不接受无组织PLY冒充有序点云。导入后图像和PLY复制到私有临时DB，源文件只读。

## 拼接与保存

在DB勾选至少两项原始点云，点击“执行拼接”。没有勾选时使用全部原始帧；结果云不能充当原始帧。使用识别参数和现有标记物配准，任一参与帧配准失败时整批不发布残缺结果；可以检查失败原因后重新选择输入。

成功结果为独立DB记录，原始帧保留，支持导出点云及点云后处理。加载和拼接在后台运行，任务完成前禁止重复任务或关闭。采集设备管理在离线窗口不可用。

新建、打开、保存、会话管理沿用正式显式会话流程，新会话默认写入项目 `sessions/`。不会后台保存或关闭自动保存；退出时提示保存、放弃或取消。已有 `outputs/experiments` 会话可直接打开，内部仍沿用mobile_chain会话格式；不会自动删除或搬移旧数据。

旧 `prototypes/industrial_offline_stitch/app/main.py` 启动命令继续兼容，实际打开正式窗口。简化原型的独立算法测试不代表正式流程。

## 验证边界

2026-11-10：69项定向检查通过。weifeng三帧实际加载和拼接生成13,933,687点结果，SDK未初始化。确认1050×650参数/操作可见，离屏使用软件预览。原生GPU、客户机打包、现场真值精度未验证。单次配准成功不证明重复稳定性，局部标记误差和最近邻残差均不能替代全云真实精度。

## 1.14.1：独立FPFH几何匹配入口

离线窗口顶部“拼接”组提供“标记物拼接”和“FPFH几何匹配”两个独立按钮。FPFH无需标记物，点击后进入当前会话的后处理窗口并自动打开参数面板。可选DB已有两项点云，也可关闭参数面板，通过“导入点云”加载独立PLY/PCD，再点击“FPFH几何匹配”；导入时务必确认单位。

34项参数全部保留，面板标签/悬停提示含用途及调试建议。选择固定参考和移动点云，计算候选、核对毫米单位和报告、确认后生成独立DB拼接结果。移动帧变换到参考帧，原始帧保留；结果随当前正式会话显式保存，并可导出完整点云。

可选去平面、ICP，支持导出全部参数与诊断JSON；参数变化使旧候选失效。同一编辑器重开面板保留最近计算参数；参数不自动写入会话配置，长期对照测试请导出JSON。完整参数表与建议见 `prototypes/fpfh_geometry_match/README.md`。原实验入口兼容保留，使用相同实现。
