壹

标记物拼接贴几个标记，剩下的交给软件

一句话原理：在工件表面贴上带编号的编码标记，相机自动认出“两张照片里的同一个标记”，据此算出两片数据的相对位置，逐帧拼合成整体。

适合谁

  • 现场没有导轨、机器人、转台，也不想改造产线
  • 一次性扫描、逆向建模、大件测绘类项目
  • 筒体、模具、铸件、叶片、框架类大型工件——搬不动、转不了、拍不全
  • 不规则小工件——凹槽、倒扣、深腔被遮挡，单视角拍不透，需多视角逆向建模

解决什么痛点

  • 全：大件单视角装不下、小件单视角有死角 → 多视角自动拼
  • 省：零工装投入，贴标就能干
  • 快：全自动，典型精度 0.5~2 mm
贰

已知变换拼接设备知道相机在哪，拍下来就是拼好的

一句话原理：相机装在导轨、机器人或转台上（或采用多相机固定阵列），每张照片的位置关系由设备精确给出、一次标定长期有效，点云自动归位。

适合谁

  • 产线在线检测、批量生产 → 多相机固定阵列，拍照即出结果
  • 圆柱、回转体 360° 全周检测 → 转台 / 托辊
  • 长筒、管道类长工件 → 编码器线扫；多品种柔性产线 → 机器人 + 手眼标定

解决什么痛点

  • 净：外观件不能贴标记 → 工件上什么都不用贴
  • 快：拍照即拼接，无人工环节，满足产线节拍
  • 精：典型精度 0.1~1 mm，标定一次长期复用
