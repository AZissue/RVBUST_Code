# 返厂 PDF 与借测照片改版

## 返厂维修单

- 新建返厂单按用户提供的横向 PDF 字段填写，关联客户和台账设备。
- 报修单位、报修人、电话、日期、SN、外观、回寄地址、销售及售后联系人作为表单快照保存；报修原因沿用 symptom 字段。
- 支持保存记录、保存并生成 PDF；详情中可补填或修改表单并重新导出。
- PDF 保留原模板和寄送须知，使用内嵌中文字体；长文本自动附页，不截断。
- 每次生成的 PDF 作为返修附件归档，并在时间线记录生成者及源记录更新时间。
- 旧返修单可补填表单后导出；已关闭单保持原有不可修改规则。
- 新建仍沿用现有已收货状态，报修日期与系统收货日期分别保存，不增加物流状态。

## 借测照片

- 每个借测设备独立保存三组照片：设备六面图最多 9 张、配件图最多 5 张、序列号图最多 1 张。
- 新建时可选择照片并预览、移除未提交照片；保存后在展开详情中查看和补传。
- JPG、PNG、WebP，前端单张不超过 10 MB；后端仍受 MAX_UPLOAD_MB 限制并校验文件头。
- 借测单成功后照片失败可重试，不重复建单；photoKey 防止同一上传被重试成重复附件。
- 后端按设备明细加行锁分配照片槽位，数据库唯一索引及检查约束保证并发下不超过上限。
- 下载沿用借测可见范围；拒绝的照片文件会清理。已归档照片暂不提供删除，保留设备出借凭证。
- 同时修复原归还表单发送 itemId 与后端要求 deviceId 不一致的问题。

## 包含此前本地修改

- 我的工作移除历史事项入口，保留底层数据。
- 工单状态标签、状态选择器、时间线增加颜色；创建人、负责人和协作人收到状态通知，排除操作者。
- 登录页采用原始公司 Logo 和相机图片，不修改素材。

## 升级

先备份数据库、上传目录和 .env，保留 AI 加密密钥。安装依赖并执行：

```sh
npm ci
npm run prisma:generate -w apps/api
npm run prisma:deploy -w apps/api
npm run build
```

新增迁移 `202609080003_repair_form_loan_photos` 只增加字段、外键和约束，不清空数据。生成 Prisma 客户端前应停止 API，避免 Windows 引擎文件被占用。测试使用 quick_ticket_test 隔离 schema，禁止对业务数据库执行 seed/reset。

`apps/api/assets` 必须随 API 部署。中文固定字重字体来自 Google Fonts Noto Sans SC，使用 FontTools 从 wght=400 实例化，许可证见同目录 Noto-LICENSE.txt。为避免字体子集兼容问题，PDF 嵌入完整字体，文件约 6.7 MB。生成的业务 PDF 和照片存储于 UPLOAD_DIR，不进入 Git。

字体来源：https://github.com/google/fonts/tree/main/ofl/notosanssc
