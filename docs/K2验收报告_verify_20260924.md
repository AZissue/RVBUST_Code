## 4. S8 目视判定的方法说明（重要）

本机目视判定由视觉模型辅助完成，但其对**原型侧**属性面板的读数（"输入框底色比面板更浅、描边偏暗"）经像素证据证伪：对 `proto_loaded.png` 做 token 精确匹配，`BG_INPUT #1E2229` 命中 23,099 px（bbox x817–1379 / y50–464，即右侧属性面板区）、`BORDER #3D4350` 命中 10,665 px；主程序 `main_ref.png` 同 token 命中 13,418 / 5,869 px。两图输入框为同一 token 对（底色 `BG_INPUT` 深于卡片、描边 `BORDER` 偏亮）→ **以像素/token 证据为准，目视读数不作判据**。据此 S8 ①③⑤⑥⑦ 判 ✅。
