**视觉上照主程序的 UI 设计语言走**（@user 2026-09-23 口径 1：主题 QSS + 字体 + 状态色全部沿用主程序，
原型不再自造色、不自设字体），使「并入主程序」退化为**加一张模式卡片 + 一个薄壳工作区文件**，而不是 UI 重写。

## 4. 推荐路线：模块划分与接口

### L1 契约层（先做）

新增 `src/ui_v2/workspace_protocol.py`（约 80~100 行）：

```python
# 真交集（@verify 探针实测 + @lead 实读复核，4 个类均有）
WORKSPACE_REQUIRED = ("log_message", "set_devices", "set_state", "current_state")
# 可选面：缺失只记 dev warning，不判 FAIL
WORKSPACE_OPTIONAL = ("dirty_changed", "set_background_runner")

def check(ws) -> list[str]: ...   # 返回缺失项，空 = 合规
```

**实现要点（v1 的写法会假绿灯，必须按此改）**：

1. **不能用 `hasattr` 判信号** —— Signal 是类属性，`hasattr` 拿到的可能是不可 connect 的类级描述符。信号判定用**实例试连**：`getattr(ws, name).connect(lambda *a: None)` 后立即 `disconnect`，抛异常即缺失；或 `isinstance(getattr(type(ws), name, None), Signal)`。
2. **方法用实例 `callable(getattr(ws, name))`** 判定。
3. 实测缺失集合（按 v1 的 `WORKSPACE_MIN` 现状即 FAIL，故该常量作废）：`multi_cam` 缺 `dirty_changed` + `set_background_runner`；`mobile_chain` 缺 `set_background_runner`；`turntable` / `robot_handeye` 无缺。
4. **`current_state()` 必须进必选集**：调用点 `backend_bridge.py:586/1032/1086`、`main_window.py:518`、`run_shell.py:99`、`smoke_test.py:67/92`。
5. 不搞 ABC 继承（不动已测通过的 2072 行存量）；`main_window.py` 接线处加一行 `check()` 开发期断言。

### L2 视觉层（原型接入公共层）

   ⚠️ 连带风险：原型 `control_panel.py` 手搓的 4 组 `QGroupBox` 会落在主程序 `QGroupBox::title`（`theme.py:192-200`）口径下改观 → 必须实跑对照（§5.3 N1）。
