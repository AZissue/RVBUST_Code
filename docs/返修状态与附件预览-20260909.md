# 返修状态与附件预览

## 使用变化

- 管理员、技术支持可在返修详情顶部修改状态，已关闭返修单可重新打开。
- 回退、跳转状态必须填写原因，历史记录保留操作人、原状态、新状态及原因。
- 已关闭返修单允许补充编辑返厂表单和处理信息。
- 返修附件、借测已上传图片点击后弹出预览，下载为独立操作；PDF 支持预览。
- 图片保持原始内容，等比显示；支持手机端与 Escape 关闭。

## 安全与兼容

- 保留后端管理员、技术支持写入权限，不向员工或客户放开状态修改。
- 回退清除关闭时间，回退到维修阶段清除寄回时间；保留历史物流编号。
- 关联设备借出、报废或存在其他未关闭返修时，禁止重新进入维修流程。
- 关闭返修不覆盖设备已经借出或报废的状态。
- 并发修改及过期状态请求被拒绝，不会静默覆盖。
- 文件预览与下载使用相同鉴权，仅图片和 PDF 允许 inline 返回。
- 不修改数据库结构、不迁移业务数据、不修改原始图片。

## 验证

- 生产构建、49 项单元测试、60 项隔离数据库接口测试通过。
- 浏览器验证：已关闭单回退成功，图片加载正常，点击预览不下载，点击下载才下载。
- 桌面、390px 手机视口截图检查，无横向溢出和 JavaScript 异常。
