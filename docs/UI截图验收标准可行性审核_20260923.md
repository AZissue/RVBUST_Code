## 2. 采样方法学（S1 为什么必须改口径）

| 探针结论 | 实测 |
|---|---|
| `widget.grab()` 对**隐藏**控件返回全 `#000000` | ControlPanel 内 1 个 QLineEdit + 2 个 QPushButton `isVisible()=False` → `#000000`。**采样前必须过滤 `isVisible()`** |
| 按钮中心点被文字污染（V2） | 15 个按钮中 13 个"边缘点 ≠ 中心点"，4 例中心点为文字色（`#E9DDFF` / `#F0FFFF` / `#816143`）。**边缘点采样成立，中心点不可用** |
| 但"右边缘 (w-6,h//2)"对 QComboBox 不可用 | 3D 工具条 2 个 QComboBox + 1 个 QSpinBox 的 `(w-6)` 与 `(w//4)` 同为 `#252525`（drop-down 区 / 组件局部 QSS）。**输入类控件改采 `(w//4, h//2)`** |
| `#252525` 不是原型硬编码 | 出处 `src/ui/viewer_3d.py:1428`（`EmbeddedPointCloudViewer` 自带局部 QSS `#252525`/`#3a3a3a`），主程序 `viewer_panel.py` 同样使用 → **S1 采样范围须排除 `EmbeddedPointCloudViewer` 子树**，否则误判 |
| offscreen 与真机色值一致（V5 关闭） | 四角/GroupBox/LineEdit/ComboBox/15 个按钮色值**逐项相同**；仅字体退化（`Sans Serif`）。→ **offscreen 组可做色值回归，真机组用于 S3 + 目视** |
| dpr | 本机 `devicePixelRatio=1.0`，脚本仍建议乘 dpr（150% 缩放机器上否则错位） |
