## 1. 背景与目标

相机配合工业机器人做多视角扫描拼接，是产线自动化的核心需求：**用机器人位姿 + 手眼标定结果直接给出每帧变换，不依赖标记物**（无纹理工件可拼）。

现状是**两套独立资产、互不连通**：

| | RvbustCloudRegistration_V1.1（桌面工具） | MCC 模式 D core |
|---|---|---|
| 定位 | 手动拼接工具（**已实机验证**，v2.1） | 自动化工作流（core 已落地，**UI 零接线**） |
| 手眼矩阵 | **手填** 4×4（TCP→Camera） | `cv2.calibrateHandEye` **自动求解**（真值测试钉死） |
| 机器人位姿 | **手填** X Y Z Rx Ry Rz + 欧拉角顺序 | `RobotInterface` 抽象（MockRobot 可测；真实协议待实现） |
| 拼接 | numpy 齐次变换合并，每片分色 | 增量合并（o3d） |
| 流程 | 手动逐行录入 → 合并 → 预览/保存 | capture_frame 自动化（拍帧+记录位姿+变换+合并） |
| 附加价值 | 中文路径 IO 绕过、颜色图例、日志、PyInstaller 打包 | 误差评估（rms_t_mm/rms_r_deg）、真值测试、JSON 持久化 |

**本方案目标**：把两套资产整合为一条完整的"机器人配合拼接"能力链——**标定求解（自动）→ 数据采集（连接机器人）→ 拼接（自动化）→ 封装交付（打包）**，并明确落地路线与待修缺陷。

## 2. 原理与坐标链

### 2.1 两种安装方式

```
Eye-in-Hand（相机装机器人末端，推荐）：
    T_base2cam = T_base2tool @ T_tool2cam
    p_base = T_base2cam @ p_cam
    每帧拼接：p_base = T_base2tool @ T_tool2cam @ p_cam
    手眼标定求解未知量：T_cam2tool（T_tool2cam = inv(T_cam2tool)）

Eye-to-Hand（相机固定安装）：
    T_base2cam = T_cam2base^{-1}（常数，与机器人位姿无关）
    手眼标定求解未知量：T_cam2base
```

### 2.2 两套代码坐标链一致性（已交叉验证）

- **RvbustCloudRegistration** `main.py:869-875`：`T_total = T_robot @ he_T`，其中 he_T 即 T_tool2cam（工具→相机），T_robot 即 T_base2tool → **Eye-in-Hand 链** ✅
- **MCC** `robot_stitch_workflow.py:109-120`：`compute_cam2base` 返回 `T_base2tool @ T_cam2tool`（= `T_base2tool @ inv(T_tool2cam)`）→ 同一坐标链 ✅

> 差异注意：RvbustCloudRegistration 手填的 he_T 是 **T_tool2cam**（TCP→Camera），MCC 手眼标定输出的是 **T_cam2tool**（Camera→TCP）。**两套代码都正确，但手填方向相反**——融合时以 MCC 的 T_cam2tool 为统一内部约定，入口层做转换说明。

### 2.3 OpenCV 手眼求解的参数约定（经合成实验钉死，勿照官方文档字面理解）

`handeye.py` 模块注释（第 8-28 行）总结的实测约定：

| OpenCV 参数名 | 实际含义（Eye-in-Hand） |
|---|---|
| `R_gripper2base / t_gripper2base` | **T_base2tool**（基座→工具法兰） |
| `R_target2cam / t_target2cam` | **T_board2cam**（标定板→相机） |
| 返回值 `R_cam2gripper / t_cam2gripper` | **T_cam2tool**（相机→工具法兰） |

### 5.1 手眼标定求解（MCC `src/core/handeye.py:105-145`，已验证）

```python
def _calibrate_eye_in_hand(self) -> Dict:
    """Eye-in-Hand：求解 T_cam2tool（相机→工具法兰）。"""
    # OpenCV 实测约定（勿照文档字面）：
    #   R_gripper2base / t_gripper2base  = T_base2tool（基座→工具法兰）
    #   R_target2cam    / t_target2cam    = T_board2cam（标定板→相机）
    R_gripper2base = [T[:3, :3] for T in self.T_base2tool_list]
    t_gripper2base = [T[:3, 3] for T in self.T_base2tool_list]
    R_target2cam   = [T[:3, :3] for T in self.T_board2cam_list]
    t_target2cam   = [T[:3, 3] for T in self.T_board2cam_list]

    R_cam2tool, t_cam2tool = cv2.calibrateHandEye(
        R_gripper2base, t_gripper2base,
        R_target2cam, t_target2cam,
        method=self.method)                      # TSAI/PARK/HORAUD/ANDREFF/DANIILIDIS

    T_cam2tool = np.eye(4, dtype=np.float64)
    T_cam2tool[:3, :3] = R_cam2tool
    T_cam2tool[:3, 3] = t_cam2tool.flatten()

    # 一致性验证：固定标定板在基座系下的位姿应恒定
    # T_base2board = T_base2tool @ T_cam2tool @ T_board2cam
    T_base2boards = [
        self.T_base2tool_list[i] @ T_cam2tool @ self.T_board2cam_list[i]
        for i in range(self.sample_count())
    ]
    rms_t, rms_r = self._compute_consistency_error(T_base2boards)
    return {'success': True, 'T_cam2tool': T_cam2tool,
            'T_tool2cam': np.linalg.inv(T_cam2tool),
            'rms_t_mm': float(rms_t), 'rms_r_deg': float(rms_r), ...}
```

**采集要求**：≥10 组样本，机器人覆盖不同角度/距离（示教位置间旋转轴不平行，否则求解病态）；每组 = `T_base2tool`（机器人控制器读出）+ `T_board2cam`（相机拍标定板 → `marker_detector` 标定板模式检测）。

### 5.2 坐标链计算（MCC `robot_stitch_workflow.py:109-120`，已验证）

```python
def compute_cam2base(self, T_base2tool: np.ndarray) -> Optional[np.ndarray]:
    """由当前机器人位姿和手眼结果求 T_cam2base（相机坐标 → 基座坐标）。"""
    if self._T_handeye is None:
        return None
    T_base2tool = np.asarray(T_base2tool, dtype=np.float64)
    if self._eye_in_hand:
        # Eye-in-Hand: p_base = T_base2tool @ T_cam2tool @ p_cam
        return T_base2tool @ self._T_handeye          # _T_handeye = T_cam2tool
    # Eye-to-Hand: 相机固定在基座系，_T_handeye 即为 T_cam2base
    return self._T_handeye
```

```python
def capture_frame(self, camera_id=None):
    T_base2tool = self._robot.get_current_pose()      # 读机器人位姿
    T_cam2base = self.compute_cam2base(T_base2tool)  # 组合手眼结果
    frame = self.camera_manager.capture(cam_id)      # 触发相机拍摄
    self._frames.append(frame)
    self._T_base2cam_list.append(T_cam2base)
    # 增量合并：相机系点云变换到基座系
    pcd = frame.load_pointcloud_o3d()
    if pcd is not None and len(pcd.points) > 0:
        pcd_t = o3d.geometry.PointCloud(pcd)          # ⚠️ 先复制（transform 原地修改）
        pcd_t.transform(T_cam2base.astype(np.float64))
        if self._merged_pcd is None:
            self._merged_pcd = pcd_t
        else:
            self._merged_pcd += pcd_t                 # ⚠️ 属性不对称会清零，见 §7
```

### 5.4 中文路径 PLY IO（RvbustCloudRegistration `main.py:318-354`，已实机验证）

```python
class FileUtils:
    @staticmethod
    def read_ply(path):
        """open3d 读中文路径：先复制到 ASCII 临时文件再读（绕过 open3d 中文路径 bug）。"""
        import open3d as o3d
        if not os.path.exists(path):
            raise FileNotFoundError(f"文件不存在: {path}")
        tmp = None
        try:
            with tempfile.NamedTemporaryFile(suffix='.ply', delete=False) as f:
                tmp = f.name
            with open(path, 'rb') as s, open(tmp, 'wb') as d:
                d.write(s.read())
            return o3d.io.read_point_cloud(tmp)
        finally:
            if tmp and os.path.exists(tmp):
                os.remove(tmp)

    @staticmethod
    def write_ply(path, pc):
        """保存到中文路径：先写 ASCII 临时文件再搬运。"""
        import open3d as o3d
        os.makedirs(os.path.dirname(path) or '.', exist_ok=True)
        tmp = None
        try:
            with tempfile.NamedTemporaryFile(suffix='.ply', delete=False) as f:
                tmp = f.name
            o3d.io.write_point_cloud(tmp, pc)
            with open(tmp, 'rb') as s, open(path, 'wb') as d:
                d.write(s.read())
        finally:
            if tmp and os.path.exists(tmp):
                os.remove(tmp)
```

### 5.5 UR 机器人 TCP 客户端（RobotInterface 实现示例，新代码待实机验证）

```python
"""robot_ur.py —— UR 机器人（E 系列/ CB3）TCP 客户端实现。"""
import socket, re
import cv2
import numpy as np
from .robot_interface import RobotInterface

class URRobot(RobotInterface):
    """UR 控制器 Socket 接口（端口 30002 实时端口，XML 数据流）。"""

    def __init__(self, host: str, port: int = 30002):
        self._host, self._port = host, port
        self._sock = None
        self._T_base2tool = None

    def connect(self):
        try:
            self._sock = socket.create_connection((self._host, self._port), timeout=5)
            self._sock.settimeout(2.0)
            return True, "UR 已连接"
        except Exception as e:
            return False, f"连接失败: {e}"

    def disconnect(self):
        if self._sock:
            self._sock.close()
            self._sock = None
        return True, "UR 已断开"

    def is_connected(self):
        return self._sock is not None

    def get_current_pose(self):
        """读实时端口 XML 中的 actual TCP pose（6 列），转 4×4 T_base2tool。
        UR 输出为 (x, y, z, rx, ry, rz) 旋转矢量（轴角），需 Rodrigues 转矩阵。"""
        if not self._sock:
            return None
        try:
            data = self._sock.recv(4096).decode('utf-8', errors='ignore')
            m = re.search(r'<key>actual TCP pose</key><array><data>([\s\S]*?)</data>', data)
            if not m:
                return None
            vals = [float(v) for v in re.findall(r'<d>([-+0-9.eE]+)</d>', m.group(1))[:6]]
            if len(vals) != 6:
                return None
            x, y, z, rx, ry, rz = vals
            R, _ = cv2.Rodrigues(np.array([rx, ry, rz]))      # 旋转矢量 → 矩阵
            T = np.eye(4); T[:3, :3] = R; T[:3, 3] = [x, y, z]
            return T
        except Exception:
            return None

    def move_to(self, pose, blocking=True, timeout_sec=60.0):
        """经 30001 主端口发送 movej（URScript）。位姿 T_base2tool → 旋转矢量。"""
        # 本示例只读位姿；运动控制建议走 dashboard/主端口并确认安全围栏
        raise NotImplementedError("运动控制需按现场机器人配置实现，见 §7 安全提示")

    def is_moving(self):
        return False
```

## 8. 验证方法

- **手眼求解**：`python test_handeye.py`（15 组随机 A@X@B 链，无噪恢复 0.0000mm / 0.0000°，0.1mm 噪声 0.093mm / 0.021°）
- **坐标链**：`python test_robot_stitch.py`（端到端真链；变换取反 → 131mm 被抓；扰动指标偏松待收紧）
- **实机验收**：示教 ≥10 位姿采集 → 求解 → 打印 rms_t_mm/rms_r_deg（<0.5mm/<0.5° 为佳）→ 拼接 3 帧验证重叠面贴合
- 运行前提：`unset PYTHONPATH && export QT_QPA_PLATFORM=offscreen && "/d/Program Files/Anaconda/envs/rvc/python.exe" test_handeye.py`
