### 二、总体架构：双窗口模型

```
[启动小窗口 LauncherDialog]  ──连接成功──▶  [拼接主窗口 MainWindow]
   · 选工作模式                      · 顶部功能栏（设备管理/模式切换/会话/日志）
   · 设备管理（搜索/自动IP/多选）        · 按模式动态切换工作区（QStackedWidget）
   · 满足模式选机规则才可连接           · 「设备管理」按钮可随时回到小窗重新选
        ▲                                    │
        └────────── 重新选择模式/设备 ◀───────┘
```

设计原则：
- **入口即分流**：启动小窗把两种模式彻底分开，用户选完模式+设备后才进主窗口，主窗口只展示所选模式的工作区，绝不让两种模式的控件混在一起。
- **随时可回头**：主窗口顶部「设备管理」随时重新打开启动小窗，改模式、加/减设备、重连，确认后主窗口切换到对应工作区（有未保存工作时先弹确认）。
- **UI 跟随操作逻辑**：每个模式的控件、步骤、术语只服务该模式的真实操作流程（核心需求：模式 B 拍摄后**自动**检测标记物，绝不允许让用户手动点「检测」）。

### 三、启动小窗口（LauncherDialog，重构 `launcher_window.py`）

整体是一个模态对话框，左右分栏，默认尺寸约 900×560，居中显示。

```
┌──────────────────────────────────────────────────────────────────────┐
│  RVC 拼接工作站 vX.X                    [logo]                        │
├────────────────────────────┬─────────────────────────────────────────┤
│  ① 工作模式（左侧，上下两张卡片）         │  ② 设备管理（右侧）               │
│  ┌────────────────────────┐  │  [🔍 搜索 型号/IP/序列号]  [↻ 刷新]     │
│  │ ● 多相机外参标定         │  │  [⚡ 自动设置IP]  [网络配置…]            │
│  │ 多台相机固定安装，先标定    │  ├─────────────────────────────────────┤
│  │ 外参，后撤板扫描拼接       │  │  ☑ M2600R  SN:xxxx 192.168.1.10 在线 │
│  │                        │  │  ☑ M2600R  SN:xxxx 192.168.1.11 在线 │
│  ├────────────────────────┤  │  ☐ X1      SN:xxxx 192.168.1.12 离线 │
│  │ ○ 单相机移动拼接         │  │  …（多选列表，每行=一台相机）             │
│  │ 一台相机移动拍摄，自动检测  │  │                                      │
│  │ 标记物，边走边拼           │  │                                      │
│  └────────────────────────┘  │  底部提示：模式所需设备数量要求            │
│  模式说明（选中模式切换时更新）   │                                      │
├────────────────────────────┴─────────────────────────────────────────┤
│  已选 2 台 / 多相机模式至少 2 台        [取消]          [连接设备 →]      │
└──────────────────────────────────────────────────────────────────────┘
```

**1. 工作模式区（左侧）**
- 两张可选中卡片（QRadioButton 样式化或自绘卡片），默认选中「多相机外参标定」。
- 卡片内容：模式名 + 一句话说明 + 图标（复用 `icons.py`，多相机用 🎥、单相机用 🔗）。
- 切换模式时：更新卡片下方「模式说明」文字；刷新右侧已选数量提示；**清空**设备多选（不同模式设备要求不同，防止残留选择误导）。

**2. 设备管理区（右侧）**
- 搜索框：按 型号 / 序列号 / IP 实时过滤列表，输入即过滤。
- 「刷新」按钮：重新枚举设备（调用 SDK `SystemListDevices`，无 SDK 时列表为空并提示「未检测到相机」）。
- 「自动设置IP」按钮：调用自动网络配置逻辑（参考 SDK 示例 `AutoConfigureNetwork.py`）；执行中显示加载遮罩，完成后刷新列表并提示结果。
- 「网络配置…」按钮：弹出网卡选择对话框（GigE 相机需要，列出本机网卡+子网，选择后应用静态 IP，参考现有 device_panel 逻辑）。
- 设备列表（核心控件）：多选表格/列表，每行显示：
  - ☑ 多选框 | 型号（M2600R/X1/M2000…）| 序列号 | IP 地址 | 状态徽标（● 在线绿 / ○ 离线灰）
  - 排序：在线在前，其余按枚举顺序。
  - 多选交互：点击行切换勾选（不要搞成只能单选）。
- 设备数量提示（模式联动规则，连接按钮的启用条件）：
  - **多相机外参标定：必须选中 ≥2 台**，不足时底部提示「多相机模式至少需要 2 台相机」且「连接设备」禁用置灰。
  - **单相机移动拼接：必须且只能选中 1 台**，选 2 台及以上时提示「单相机移动拼接仅支持 1 台相机，请取消多余选择」。
  - 提示随选中数量实时更新（如「已选 2 台 ✓」变绿）。

**3. 底部按钮**
- 「连接设备 →」：校验通过后执行连接（调 CameraManager，逐台连接并显示进度），全部成功 → 关闭小窗返回 Accepted；部分失败 → 弹窗列出失败设备，已成功的保留，用户可重试或仅用成功的进入。
- 「取消」：直接退出程序。

### 四、主窗口框架（重构 `main_window.py`）

```
┌────────────────────────────────────────────────────────────────────────┐
│ [⚙ 设备管理] [模式▾] [💾 保存会话] [📂 打开会话] [🧹 后处理] [📋 日志] [❓帮助] │ ← 顶部功能栏
├────────────────────────────────────────────────────────────────────────┤
│                        QStackedWidget                                  │
│   ┌── 多相机工作区（模式A）──┐    ┌── 单相机工作区（模式B）──┐            │
│   │ 步骤条 + 面板 + 3D视图   │    │ 机位时间线 + 面板 + 3D视图 │           │
│   └─────────────────────────┘    └──────────────────────────┘           │
├────────────────────────────────────────────────────────────────────────┤
│  状态栏：模式 | 设备在线 n/m | 当前步骤 | 最近误差/建议                   │
└────────────────────────────────────────────────────────────────────────┘
```

**顶部功能栏（QToolBar 或自绘按钮栏）**：
1. **「设备管理」**：重新打开启动小窗（LauncherDialog），回填当前模式与已连接设备（勾选状态），用户改选后确认 → 主窗口切换到对应工作区；取消则保持现状。**打开前若有未保存的标定/会话数据，先弹确认框**。
2. **「模式」**：下拉/按钮显示当前模式（「多相机外参标定」/「单相机移动拼接」），点击同设备管理（回小窗），两种模式工作区互不干扰、各自独立状态。
3. **「保存会话 / 打开会话」**：会话存 `scans/<mode>_session_时间戳/`（沿用现有 OfflineSession 逻辑），打开后恢复该模式工作区状态。
4. **「后处理」**：弹出参数面板（裁切范围 / 下采样 / 离群点滤波），两种模式共用。
5. **「日志」**：toggle 右侧日志面板（复用现有日志组件）。
6. **「帮助」**：关于对话框 + 操作说明入口。

主窗口由 `QStackedWidget` 承载两个独立工作区（或按模式实例化对应工作区），切换时只显示当前模式。

### 五、模式 A：多相机工作区（固定多相机外参标定）

**布局（三栏）**：

```
┌──────────────┬────────────────────────────────────────────┬──────────────┐
│ 左面板        │ 中央：相机取景网格                           │ 右面板        │
│ ① 设备列表    │  ┌────────┐ ┌────────┐ ┌────────┐          │ ③ 标定/扫描   │
│   (已连n台)   │  │ cam0    │ │ cam1    │ │ cam2    │        │   Tab        │
│ ② 拍摄控制    │  │ [缩略图] │ │ [缩略图] │ │ [缩略图] │        │   ·标定Tab    │
│   ·同步/异步  │  │ 标记:12  │ │ 标记:9  │ │ 标记:0● │        │   ·扫描Tab    │
│   ·拍摄按钮   │  └────────┘ └────────┘ └────────┘          │              │
│   ·参考相机   │  每卡片角标：标记数 / 共视状态                 │              │
│              │────────────────────────────────────────────│              │
│  步骤条(顶部) │ 底部：3D 拼接预览（viewer_3d 复用）           │              │
└──────────────┴────────────────────────────────────────────┴──────────────┘
```

**① 顶部步骤条**（复用 `wizard_step_bar.py`，横向向导）：
`连接相机 → 拍摄标定 → 检测标记 → 计算外参 → 扫描拼接 → 保存`
- 当前步骤高亮；前置步骤未完成时后续置灰；已完成步骤可点击回退。
- 步骤条是本模式操作逻辑的骨架，**步骤状态由状态机驱动，按钮可用性跟随步骤**。

**② 左面板**：
- 已连接设备列表（只读，显示型号/IP/状态）。
- 拍摄控制区：同步/异步拍摄切换（QRadioButton 或 SegmentedButton，默认同步）→「拍摄」按钮（触发全部相机拍摄，加载遮罩，完成显示各卡片缩略图）。
- 参考相机下拉框（默认第一台，参与标定计算）。

**③ 中央相机网格**：复用 `camera_card.py`，每台相机一张卡片：
- 实时缩略图（拍完刷新）+ 相机名 + 检测到的标记数量角标。
- 共视状态角标：绿色「✓ 共视正常」；某相机标记数 = 0 时红色「● 未看到标定板」（标定阶段此角标是硬提示）。
- 标定帧与扫描帧用 Tab 或标签色区分（`标定帧` / `扫描帧` 分区，互不覆盖）。

**④ 右面板：标定 Tab**（对应步骤 ③④）：
- 「检测标记物」按钮（检测编码圆 / 标定板，两种检测方式可切换）。
- 标定结果表格：`pair | RMS(mm) | 内点率 | 状态`，绿/黄/红配色（RMS<0.5mm 优🟢 / <1.5mm 良🟡 / 以上差🔴）。
- 标定质量评分条 + 逐点误差详情列表。
- 「保存外参 / 加载外参」按钮（JSON，复用 CalibrationEngine）。
- 质量门禁：任一 pair 未达标（红）时，禁止进入扫描阶段（扫描按钮置灰 + 提示）。

**⑤ 右面板：扫描 Tab**（对应步骤 ⑤⑥）：
- 顶部**撤板提醒横幅**：「🔒 外参已锁定 — 请移除标定板后开始扫描，拍摄期间请勿移动相机」。
- 「开始扫描」按钮 → 「拍摄扫描帧」→「拼接并保存」（复用 StitchEngine）。
- 支持「连续拍摄 N 次 → 批量拼接保存」选项（产线巡检场景）。
- 外参锁定指示 + 相机断线重连后提示「外参可能失效，请重新标定」。

**状态机（模式 A 核心逻辑，UI 必须严格跟随）**：
```
待机 → 连接相机(≥2) → 拍摄标定帧 → 检测标记物
     → 计算外参 → 质量检查(RMS/内点率)
         ├─ 通过 → [外参锁定] → 撤板 → 开始扫描 → 拍摄扫描帧
         │        → 应用外参拼接 → 保存PLY →（可循环扫描多次）
         └─ 不通过 → 提示重拍/重新检测，禁止进入扫描
```

### 六、模式 B：单相机工作区（移动链式拼接）

**布局（左时间线 + 中央上下分栏）**：

```
┌──────────────┬──────────────────────────────────────────────────────┐
│ ① 机位时间线  │ ② 中央上部：实时取景（自动检测叠加）                    │
│  (竖排)      │  ┌──────────────────────────────────┐                │
│  #1 ●12/94%  │  │ [实时图像 + 绿框编码圆+code号]     │                │
│  #2 ●9/91%   │  │ [上一机位共有标记: 蓝色圆圈提示]     │                │
│  #3 ●7/0.4mm │  └──────────────────────────────────┘                │
│  #4 ●重拍按钮 │ ③ 中央下部：实时 3D 拼接预览（按机位分色）              │
│  …           │  ┌──────────────────────────────────┐                │
│  [+ 闭环提示] │  │ 已拼接点云，彩色按机位区分，增量刷新  │                │
├──────────────┴──┬───────────────────────────────────────────────────┤
│ ④ 评估卡片       │ ⑤ 操作按钮区                                      │
│ 本步: 共视9 内点率94% │ [📷 拍摄机位] [↩ 撤销上一步] [🗑 重拍当前]      │
│ RMS 0.42mm 🟢  | 建议: 重合度充足,可继续移动  │ [💾 保存拼接数据]        │
└─────────────────┴───────────────────────────────────────────────────┘
```

**① 机位时间线（本模式核心创新控件）**：左侧竖排节点链 `#1 → #2 → #3 → …`
- 每个节点卡片显示：机位号、共视标记数、与上一机位重合度、误差 mm、状态色标（🟢 通过 / 🟡 谨慎 / 🔴 失败）。
- 当前机位高亮；失败机位节点显示「重拍」按钮；点击任意节点可选中 → 提供「重拍该机位 / 删除该节点（后续链自动重算）」。
- 链末尾检测到与早期机位共视时，节点间出现「🔁 发现闭环，可优化全局精度」按钮 → 点击执行全局优化，弹出优化前后误差对比。

**② 实时取景（自动检测）**：中央上部单相机实时画面。
- **拍摄后自动执行检测**（核心需求：不提供手动「检测」按钮，自动跑）：
  1. 检测编码圆 → 绿框 + code 号叠加显示；
  2. 自动匹配与上一机位的共有标记 → 共有标记用蓝色圆圈高亮，提示用户「保持这些区域在视野内可提高重合度」；
  3. 上一机位标记在当前视野中的位置以半透明蓝圈提示（引导移动时保持重叠）。
- 高级用户入口：「自动/手动」切换开关（默认自动；手动模式才显示原有手动 pair 标定面板，作为兜底）。

**③ 实时 3D 拼接预览**：`viewer_3d` 复用，每成功入链一帧增量刷新，按机位分色，用户「边走边看结果」。

**④ 评估卡片**（每拍一帧后自动弹出/更新，不阻塞操作）：
- 显示：共视标记数 / 内点率 / RMS(mm) / 建议动作。
- 三色语义：🟢 绿「重合度充足，可继续移动」；🟡 黄「可继续，建议减小移动距离」；🔴 红「配准失败，请重拍或微调位置后重试」。
- 评估结果同步写入机位时间线节点，形成可回放记录。

**⑤ 操作按钮区**：
- 「📷 拍摄机位」：主操作按钮（大、醒目）。拍完自动走 检测→匹配→评估→入图 全流程。
- 「↩ 撤销上一步」「🗑 重拍当前」：防误操作兜底。
- 「💾 保存拼接数据」：保存会话 + 拼接点云 PLY + 误差报告（`error_report.json`）。
- **防误操作规则**：拍摄按钮与「移动到下一机位」语义分离；上一帧评估通过前不覆盖已拍机位数据（帧即存盘，复用 StationManager）。

**状态机（模式 B 核心逻辑，UI 必须严格跟随）**：
```
待机 → 连接相机(1台) → 拍摄机位1 → 自动检测标记物 → 机位1入链
     → 提示移动 → 拍摄机位N → 自动检测 → 自动匹配共有标记
     → 评估(共视≥6 / 内点率≥0.7 / RMS达标)
         ├─ 通过🟢 → 加入位姿图 → 实时拼接刷新 → 提示继续移动
         ├─ 谨慎🟡 → 入图，建议减小移动距离
         └─ 失败🔴 → 拒绝入图，提示重拍/调整位置
     → 检测到与早期机位共视 → 提示可闭环 → 全局优化
     → 完成 → 保存会话+点云+误差报告
```
**底部状态栏常驻**：`已接 N 机位 | 累计误差 X mm | 平均单步误差 Y mm`，超阈值变红并建议做全局优化。
