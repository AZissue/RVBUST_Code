## 1. 目标与验收标准

**目标**：原型 UI **一次性**对齐主程序 ui_v2 的设计语言 —— 不是"换几个色号"，而是
**外壳（顶栏/状态栏/浮动日志）+ 左控制面板 + 状态色 + 字体/圆角/间距**全部走 ui_v2 的公共层（`ui_v2.theme` token + `GLOBAL_QSS` + `ui_v2.widgets`），
并在**真实桌面会话**下产出可复核的运行截图；「并入主程序」时不再有视觉返工。

## 3. 候选路线对比

| 路线 | 做法 | 优点 | 代价 / 风险 | 适用条件 |
|---|---|---|---|---|
| **① 外壳复刻 + 全量 QSS 化 + 截图脚本**（推荐） | 宿主补 `GLOBAL_QSS`/顶栏/状态栏/`FloatingLogPanel`；左面板 `QScrollArea` + 11 处色值入 token + 主按钮 `objectName("primary")`；dev 交 8 张固定命名截图 | 一次性收口；改后与主程序同设计语言；截图作为可复核证据链 | 需真机跑一次截图（verify 人工）；左面板高度 +391px 必须一并滚动化 | 原型继续独立可跑 |
| ② 只做 v3.1 原 M2（换色 + 日志面板） | 沿用原 M2 三条 | 成本最低（1.0 人日） | 仍留"没有顶栏/状态栏/滚动区/截图标准"的尾巴 → @user 本轮要的"一次性复刻"没兑现 | 不推荐 |
| ③ 原型直接内嵌 `MainWindowShell` | 宿主换成主程序壳 | 视觉 100% 相同 | `QMainWindow` 嵌 `QMainWindow` = 批 4.5 明确规避的第一类返工；原型失去独立可跑/`--smoke` 验证形态 | 否决（与"验证形态=交付形态"冲突） |

**推荐 ①**。理由：②留返工尾巴，③破坏原型独立可验证。①是唯一在**保原型 `--smoke` 验证形态**的前提下把设计语言 100% 拉平的路线。

**截图标准为什么必须真机跑**（补充 ① 的硬性条件）：实测 offscreen 下中文全 tofu、`app.font().family()` 返回 `Sans Serif`、窗口平台样式非 Windows → 字体/中文/控件尺寸类判据在 offscreen 无效。故主判据走真实桌面，offscreen 仅作色值回归。

### 4.4 @lead 裁定（2026-09-23，依据 @verify `docs/UI截图验证报告_20260923.md`）

**裁定 1 —— D1（S4 证据不在截图里）：采纳 verify 修法，判**"需修改"**。**
4 张状态图必须能**在窗口整图里看到状态行**：截图前把状态标签滚动进可见区（状态行在宿主 y=973、左面板视口 749px、滚动 value=0/510 → 现图上完全在窗口外）。S4 断言改为"窗口整图标签矩形取色 + `visibleRegion()` 非空"，**禁止 `sl.grab()` 单控件取色**。
口径依据：U8 是"运行实测截图审核"，脚本内部取色 PASS 而截图上核验不到，等于没有证据。

**裁定 2 —— D2（S3 无判别力）：采纳 verify 修法，判**"需修改"**。**
真机组严格断言 `widget.font().family() == "Segoe UI"`；删除 `Microsoft YaHei UI` 白名单项（该值在 QSS 失效时同样是 `Microsoft YaHei UI` → 假 PASS，@verify 变异实测）。

**裁定 3 —— D3（FAILED 态状态栏冲突）：判**"加第 4 态"**，实现口径见 §5 M2c-1。**
理由：面板已用红字表达 FAILED，状态栏却仍是黄点「矩阵已加载 · 未 VERIFIED」，同一窗口两种语义 → 现场会把"门禁未通过"误读成"只是还没验"。状态栏 = 状态点 + 文案，必须与面板同源同色。
边界：只改**原型侧**两文件（`window.py` 的 `STATUS`/`_refresh_state` 分支 + `host.py:61-64` 映射表），**不改主程序**；`failed` 进 `current_state()` 后 `main_window.py:518` 会落到 `STATUS_WARN` 黄点，列为**并入批待办**（写进 §5 变更记录行/CHANGELOG）。

**裁定 4 —— S8 与 S2 补口径：采纳。** S8 只目视（两图 1461 vs 1400 不等宽，不做像素比对）；S2 只判 1400×850 档（1261×600 档实测 1.25% 只记录）。

**本轮开工口径**：@dev 只做 **D1 + D2 + D3**（M2c，≈0.25 人日），**不进 M3**；@verify 只复判这三项（D1 用窗口整图取色 + 目视 4 张状态图，D2 重跑变异，D3 看状态栏四态文案/色），全过后再进 M3（薄壳 + CHANGELOG）。
