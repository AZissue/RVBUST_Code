## 1. 摘要

1. 目标子功能（加载手眼矩阵 + 取机器人位姿 → 实时把点云转到机器人基座系 → 3D 显示/保存）已完成**方案定稿 v2** 与**两轮独立实跑验证**（@feas / @qa 各自探针，未互引）；方案落位 `prototypes/robot_handeye_transform/`，工作量约 **8 人日**（批 0~4）。
2. 验证阶段的**主要产出不是"链路可行"（该结论早已被 @feas 用厂商 `HandEyeSDK.dll` 当 oracle 钉死，逐点偏差 0.000076/0.000073/0.000064 mm），而是**废止了三条会被误当门禁的判据**：内符合 `rms`（退化数据下恒 0）、两帧重合度快检（δ∥位姿旋转轴时数学恒等为 0，实测 median 0.263 mm 放行了错 110 mm 的矩阵）、范数比值单位自检（18 场景只拦 6/18 且误拦正确矩阵）。
3. v2 已把门禁唯一化为**戳点绝对度量**（`mean ≤ 0.7 mm` 硬门禁），单位改为**显式必选无默认**（删 `unit="auto"`）+ `‖T_handeye[:3,3]‖ ∈ [5,2000] mm` 物理窗口，并新增 **A9** 把"判别下限 ≈1.0 mm"写进方案 / README / UI 三处。
4. **当前实跑状态**：A3 / A5 / A8 已有实测（探针级）；A1 / A2 / A4 / A6 / A7 **不可实跑**（`tests/` 与 `core/` 未创建），任何"已验证"表述对这几条均不成立。
5. **阻塞下游的只有一件用户侧信息**：现场手眼矩阵**有没有落成文件**（v3.9.0 手册全文无"导出结果"功能）——这一条与 1000× 尺度错是同一个入口，也是本原型唯一"跑通但结论错"的入口。

## 2. 背景与目标

- 用户需求：并入"机器人配合"能力 —— 用手眼标定矩阵 + 机器人位置把点云变换到机器人坐标系；先按流程出**子功能验证**，落位 `D:\RVC_SRC\Python\MultiCameraCalibration\prototypes`，复用主功能 UI。
- 方案目标（v2 §1）：**无机器人硬件、无相机**即可闭环验证该链路正确；真机上可一键接入。
- 关键范围界定（D1）：**不含标定求解**。标定已由独立工具 `RVHandEyeCalibration v3.9.0` 与 `src/core/handeye.py` 两处落地，原型只吃其输出，避免把"标定质量"与"变换链路"两件可独立验证的事耦在一起。

### 4.2 被废止的三条判据（本阶段最重要的结论）

| # | 原拟判据 | 为什么不能用 | 证据 |
|---|---|---|---|
| 1 | 内符合 `rms_t_mm / rms_r_deg` 当可用性门禁 | 单轴退化标定数据下**恒为 0**：`success=True, rms_t=0.000, rms_r=0.000`，真值平移误差却有 110 / 120.96 mm | @qa 12 组仅绕 Z（θ∈[-40°,40°]）→ 误差 **110.000 mm**，加 1 组离面姿态 → 误差 **0.000 mm**；@feas 另一场景 **120.962 mm**。**两方独立复现** |
| 2 | 两帧重合度快检当门禁 | 两帧相对错位 = `‖R₁δ − R₂δ‖`，当平移误差 δ **平行于两位姿旋转轴**时**恒等于 0**（数学恒等，与噪声无关） | @feas 轴向分解：δ∥轴 → median/p95 = **0.000/0.000 mm**（判 PASS），δ⊥轴 → 105.6/140.9 mm；@qa 同轴两位姿 median **0.263 mm**（1.0 mm 阈值下放行错 110 mm 的矩阵），跨轴 6.359 mm 才抓住 |
| 3 | `‖T_handeye‖ / ‖T_base2tool‖` 比值启发式（0.2~5.0） | ÷1000 方向无判别力 + 误拦正确矩阵 | @feas 18 场景：旧判据**只拦 6/18**（正确 1.48 vs 误读 1.40 同带宽）；工具靠近基座原点（`‖t_base2tool‖=37.4 mm`）时正确矩阵比值 **7.52~47.1 → 误拦**；@qa 独立复现同向结果（1.48 vs 1.40；7.52 被误拦，基座系质心差 113.684 mm） |

### 4.3 收敛后的判据（来源：方案 v2 §1 / §4.2）

- **A3 门禁路径唯一化**：**戳点绝对度量**；`mean ≤ 0.7 mm` 硬门禁（两方 P99 口径一致：@qa mean P99 0.691 mm、@feas 0.466/0.445/0.440 mm）。两帧重合度**降 warning**（须 ≥30° 旋转差对、报 p95、且必须显示轴向盲区提示）。
- **A2 单位**：显式必选（无 auto、无默认）+ `‖T_handeye[:3,3]‖ ∈ [5,2000] mm` 物理窗口（@feas 18 场景拦 18/18、0 误拦）+ 读入后必须过一次绝对度量复核；往返换算差 <1e-6 mm 且**必须用同一矩阵往返、不许重新推导**（@qa 的达成前提）。
- **A9 判别下限**：平移 **≈1.0 mm**（1.0 mm 检出 100%、0.5 mm 检出 0~30%、0.2 mm 不可判；旋转 0.5°→1.24 mm、1.0°→2.38 mm），禁止下游当亚毫米保证。
