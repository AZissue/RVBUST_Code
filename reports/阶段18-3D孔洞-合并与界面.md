# 阶段 18：「3D 孔洞」合并与界面（圆环拟合 + 孔径）

> 2026-10-21。用户要求：把「圆环拟合」与「孔径(孔洞边界法)」合并成一个工具
> 「3D 孔洞」，界面按 `MyUIdesign/2.html`（未入库）实现，并给出后端可行性与方案。

## 1. 结论：后端可行，而且是"参数化"而非重写

两个旧工具的算法入口是同一个 `MeasureTools::measureBoundaryCircle()`：

- 从 ROI 中心沿 360° 分扇区找边界点；
- 对边界点做平面代数最小二乘圆；
- 输出直径 / 半径 / 圆心 / 圆度（半径极差）/ 扇区覆盖。

唯一差别是一个布尔：

| 旧工具 | 调用 | 语义 |
|---|---|---|
| 孔径(孔洞边界法) | `materialInside = false` | 从内向外找**孔壁**（材料在轮廓外侧） |
| 圆环拟合 | `materialInside = true` | 从外向内找**材料外缘**（材料在轮廓内侧） |

所以合并没有算法风险：把布尔暴露成界面上的「探测方向」，两套结果字段
（孔直径 vs 圆环直径）共用同一份输出。旧 `RingCircle` / `HoleDiameter`
枚举值**保留不动**，只为旧数据/日志兼容；方法目录只暴露一项
`Hole3D`（id `hole3d`）。

配色与 1.html 同源：主色 `#1890ff`、成功 `#52c41a`、危险 `#ff4d4f`、
正文 `#1e293b`、次要 `#64748b`、页面底 `#f4f6f8`；白卡圆角 8 + 细边框。

**置灰项的判断**：这些模式在当前后端没有实现（边界框 ROI、圆形 ROI、
批量多孔、45° 斜向探测），保留排版但不假装可用；探测角度只在单孔圆周
路径上有意义，后端固定 0°（整圈等分）。离群点移除不另做一遍——圆拟合
本身已按径向残差剔除离群扇区，再叠一层会给出无法解释的"双重过滤"。

## 4. 数据流与一致性

1. `onMeasure()`：读公差 → `setCustomTolerance(true, nominal+lo, nominal+hi)`
   → `runMeasurement(true)`。
2. 基类 `compute()` 回调取 ROI 点 → `measureBoundaryCircle(..., materialInside())`。
3. 成功：结果行写入基类（快照/日志照常），本页把数值画进结果页；
   失败：底栏红字给出 `lastHintText()`，不切换页签。
4. `onAddToSequence()`：数值追加到本页 `m_sequence`，同时写进基类共享
   `seriesStore()[primaryKey()]`——「重复性」页仍能统计同一序列。
5. 3D 工具栏切「偏差着色」：`MainWindow` 调 `setDeviationColoring()` →
   本页更新自绘开关 → `rerun()`（基类 `run(false)` + 本页 `updateResultDisplay()`），
   不写新的 `[测量-结果]`。
6. 新一帧点云：`resetResult()` 把结果面板复位为「等待测量」，序列不动。

无图像时仍走 3D 回退（与旧孔径工具一致）；图像可用时用灰度边缘做亚像素
精修，结果里的圆度/覆盖口径不变。

## 6. 人工验收清单

1. 打开「工具」→「3D 孔洞」。
   **预期**：默认停在「1. 参数配置」；探测方向 = 从内向外；ROI 状态为未选择。
2. 拍照后在 2D 视图框住一个孔（框内要有孔 + 孔外约 2 个点距的材料）。
   **预期**：「探测位置边界」起止值自动回填；底栏提示 ROI 已就绪。
3. 点「▶ 开始测量」。
   **预期**：自动切到「2. 测试与结果」；大数字 = 孔径，明细含半径/圆心/
   圆度/扇区覆盖；状态按标称 ±0.05 mm 显示 OK 或 NG。
4. 改标称值为实测值附近，重新测量。
   **预期**：判定从 NG 变 OK（公差实时生效）。
5. 点「➕ 添加到序列」两次（中间再测一次）。
   **预期**：N 组数据递增，最大/最小/平均/极差随之更新，历史最新在上；
   按钮在添加后禁用，重新测量后恢复可用。
6. 切到「重复性」工具。
   **预期**：序列下拉里能看到 3D 孔洞的主值序列，统计与结果页一致。
7. 把探测方向改为「从外向内」，框住圆形件外缘（框内是材料 + 外侧空白）。
   **预期**：明细变成外缘直径/半径，数值接近外径；框到内孔时会量到内孔
   （这是模式的预期行为）。
8. 切到 3D 视窗点「偏差着色」。
   **预期**：点云按半径偏差着色；结果页数值保持，不被清空；再点一次恢复。
9. 换一帧新点云（重拍）。
   **预期**：结果页回到「等待测量」，序列与统计保留。
10. 把窗口缩到 640 宽，切两个页签。
    **预期**：页内滚动，无横向滚动条，按钮与数值不被裁切。

## 7. 已知限制 / 后续

- 旧日志/旧备份里的 `ring_circle` / `hole_diameter` 仍能读（枚举保留），
  但新界面不再产生这两个 id；若下游脚本按名字匹配，需要改成 `hole3d`
  并读「探测方向」。
- 只支持单个圆孔 / 单个外缘；批量多孔、椭圆、非整圈（45° 扇区）未实现，
  界面已置灰。
- 精度判据仍是 `circle_truth`（合成真值）与 T-012（真机）；合并本身不改
  kernel，所以历史精度结论继续有效——包括"边缘选择"这一已知主因。
- 「3D 孔洞」是唯一自绘整页的测量页；新增自绘页时要遵守基类的
  `resetResult/rerun/setDeviationColoring` 约定，否则 3D 工具栏同步会
  清空结果或不重绘。
