## 0. 一句话结论

**"误差较大"复现了，而且定位到了唯一一个原因：边缘选择。**
当工件在材料边界之内还有第二道跃变（台阶 / 槽 / 沉孔）时，
两个工具都会**停在靠里的那一道**，并且**报 `reliable = yes`**：

| 场景（图纸 Ø） | 实测 | 误差 |
|---|---|---|
| 圆盘 Ø26，内圈 R12 处有一道台阶 | **23.9998** | **−7.69%** |
| 圆盘 Ø26，内圈 R10 处有一道台阶 | **20.0008** | **−23.07%** |
| 孔 Ø9，孔口沉孔到 R6 | **8.9995**（孔壁） | **−25.00%** |
| 孔 Ø9，孔口沉孔到 R5.5 | **8.9995**（孔壁） | **−18.19%** |

除此之外的所有情形（平面 + 圆形边界、倒角、模糊、噪声、大倾角、离轴、镜头畸变）
**全部在 0.5% 判据之内**，多数在 0.05% 以内。
所以 **子像素算法、像素→平面映射、亚像素步长都不是问题** —— 方案里排在前面的
L1（仿射 vs 单应）、L4（步长/抛物线）**实测收益极小，应当降级**。

另有一个独立缺陷：**没有可用图像时，圆环拟合返回 "找不到材料边界"，一个数都给不出**
（孔有兜底，圆盘没有）。

## 1. 这套回归测的是什么（`tests/circle_truth.cpp`）

不需要相机、不需要 SDK，纯计算，已注册进 ctest（`circle_truth`，约 28 s）：

- 场景 = 一块**倾斜平面**被**针孔相机**成像。倾斜是刻意的：这样投影到图像上是
  **真正的单应**而不是相似变换，才能检验 kernel 用 6 参数仿射拟合"像素→平面"的代价。
- **点云**按对齐 RGB-D 传感器的作法生成：网格格点 (a,b) 就是"过图像像素
  ((a+0.5)·s, (b+0.5)·s) 的射线"与表面的交点 —— 与真实相机同构。
- **图像**同一场景渲染：4× 超采样 → 高斯 PSF（`blurPx`）→ 盒式降采样 → 灰度噪声。
  表面是**多能级**的（背景 30 / 顶面 200 / 下沉面 140），所以台阶既体现在几何上，
  也体现在亮度上 —— 这正是"选哪一道跃变"这件事的成因。
- 每个场景直接读回 `measureBoundaryCircle` 的直径、圆心、圆度、扇区覆盖率、
  `subpixel` / `reliable`，与已知真值对比。

**诚实性设计**：出画（特征 + 边距超出图像范围）的场景会被标 `OUT OF FRAME` 并跳过 ——
第一轮就是这么发现我自己造的两个"离轴"场景其实特征中心落在图像外，
那一轮的 −1.48% 是我场景的错，不是 kernel 的错。

## 2. 实测结果（31 个场景）

### 2.1 通过的部分 —— 这些**不用改**

| 情形 | 实测误差 |
|---|---|
| 孔 Ø5 / Ø6 / Ø9 / Ø26，理想 | 0.011% – 0.029% |
| 孔 Ø6，blur 1 px + 噪声 2 级 | −0.020% |
| 孔 Ø26，blur 1 px + 噪声 2 级 | 0.012% |
| 孔 Ø9，**离轴 25 mm** + k1=0.15 | **0.110%**（最坏） |
| 孔 Ø6，倾角 45° | −0.045%（但覆盖率掉到 0.35） |
| 圆盘 Ø26，理想 / blur 1 px | −0.003% / −0.004% |
| 圆盘 Ø26，**离轴 20 mm** + k1=0.15 | 0.084% |
| 孔 Ø6/Ø9，孔口倒角 0.5 / 1.0 mm | 报**孔口**，误差 ≤0.02% |
| 圆盘 Ø26，边缘倒角 0.5 mm | 报**轮廓**，误差 −0.003% |
| **无图像**（走 3D 兜底）：孔 | 0.070% – 0.193% |

两条重要的**好消息**：

1. **"图纸 Ø = 孔口"这个约定，代码本来就是对的**：带倒角的孔报孔口、实心盘报轮廓，
   都对得上图纸。所以 L5 不是"改算法"，而是"要确认图纸指的是哪一道"。
2. **仿射映射够用**：离轴 25 mm + 畸变 15% 也只偏 0.11%。L1 不值得优先做。

### 2.2 失败的部分 —— 两个真实缺陷

**缺陷 A：多跃变工件选错边缘（6 个场景，误差 7.7% – 25%）**

扫描从种子出发，**遇到第一道跃变就停**，没有继续找到"最外的材料边界"：

- 圆盘：种子在材料内，向外扫，先撞到内部台阶（R12 / R10）就停了 → 报台阶直径。
  （同一场景**没有台阶**时报 25.999，说明外缘本身够得着，不是搜索范围不够。）
- 孔：种子在孔内，向外扫，先撞到孔壁（R4.5）就停了 → 报孔壁，
  而图纸要的是孔口沉孔（R6）。

**最危险的不是偏得多，是它不吭声**：四个场景全部 `subpixel=yes, reliable=yes`。
现场拿到 `23.9998` 和拿到 `25.999` 是一样的提示强度，唯一能看出不对劲的线索是
圆心偏了 0.5–2.0 mm（可圆心本来就不是重点）。

**缺陷 B：无图像时圆环拟合给不出结果（2 个场景）**

`contour3d`（外缘的 3D 轮廓兜底）只在 `if (map.ok)` 里构造，而 `map.ok` 需要有效图像。
于是**没有图像 = 直接返回"找不到材料边界"**，文档里写的 3D 兜底不可达。
孔的分支在 `measureBoundaryCircle` 末尾有 `holeBoundary(pts)` 兜底，所以孔有数、圆盘没有。
（`results.json` 里 `disc_d63_5` 那条 "没有读到任何读数" 很可能就是这个。）

### 2.3 方案里 L0–L6 的改判

| 项 | 原判断 | 实测后的判断 |
|---|---|---|
| L0 先测真机数字 | 必须最先做 | **仍然要做** —— 本回归测的是**算法**，测不到真机图像质量与真机点云，两者不能互替 |
| L1 仿射 → 单应 | 最大嫌疑 | **降级**。离轴 25 mm + 畸变仅 0.11%，收益远小于风险 |
| L2 边缘选择 | 为某工件调的启发式 | **升级为唯一主因**，7.7%–25%，必须重做 |
| L3 梯度平滑 | 与 L2 一起做 | **降级**。blur 1 px 下已 0.01–0.03%；只有 blur 2 px + 噪声 4 级才到 0.19% |
| L4 步长/抛物线 | 成本低收益看相机 | **降级**。亚像素精度不是瓶颈 |
| L5 Ø 的定义 | 需求题，要拍板 | **部分已答**：倒角情形本来就报孔口/轮廓；但沉孔情形选错了边，所以**得先修 L2 再谈定义** |
| L6 种子窗口固定 | 低优先 | **保留为次要**。倾角 45° 时覆盖率 0.12–0.35 且 `reliable=no`（会提示，不危险） |
| — | — | **新增**：`reliable` 标志抓不住"选错边"，需要"歧义检测"（见 §3） |

## 3. 建议的方案（按性价比排序）

### P1（核心）重做边缘选择：**列出全部候选跃变，按"最外材料边界"挑**

现在的规则是"内部强度极小值（为 Ø26 那道槽调的）否则最强梯度"，二选一且只取一个。
改成：

1. 在射线上找出**所有**满足对比度阈值的跃变，各自给出亚像素位置、对比度、方向
   （暗→亮 / 亮→暗）；
2. 按**语义**挑：孔取"材料开始"的**最外**那一道（孔口 / 沉孔口），
   圆盘取材料结束的**最外**那一道（轮廓）；
3. **候选不止一个时不要自己拍板** —— 把 1–2 个候选都报出来并标"歧义"，
   让现场决定（这正是缺陷 A 最危险的地方：现在它默默地选了一个）。

判据：§2.2 那 6 个场景回到 0.5% 以内；§2.1 的场景不许变差。
（这 6 个场景就在 `isKnownDefect()` 名单里，修好后测试会自己喊"*** FIXED ***"。）

### P2 **可调参数暴露到界面**（原 T-013，用户本次明确要求）

本回归顺带把"哪些量真的影响结果"测清楚了，这就是输入框的候选清单，
**按对结果的影响从大到小**：

| 参数 | 现在 | 实测影响 | 要不要暴露 |
|---|---|---|---|
| 边缘对比度阈值 | `max(3.0, 0.15·(hi−lo))` | **决定性**（决定选中哪道跃变） | **要** |
| 候选跃变选择策略 | 内部极小值 / 最强梯度 | **决定性** | **要**（做成"自动 / 最外 / 最内 / 手动指定"） |
| 平面带宽度 | 固定 | 中（离轴时平面拟合曾失败） | 要 |
| 离群迭代次数 / MAD k | 固定 | 小 | 可给 |
| 扇区数 | 360 | 小 | 可给 |
| 亚像素步长 / 平滑 σ | 0.5 px / 无 | **小**（L3/L4 已降级） | 可给，但优先级低 |

### P3 修缺陷 B：没有图像时，圆环拟合应有 3D 外缘兜底

把 `contour3d` 的构造移出 `if (map.ok)`，或给圆盘分支补一个 `holeBoundary` 式的
纯 3D 外缘拟合。**注意**：这会改行为（现在返回失败、改后返回一个数），
需要在界面上把"这个数是 3D 粗值"标清楚（不达标就说"参考值"）。

### P4 给 `reliable` 加上"歧义"这一维

`reliable` 现在只看覆盖率/圆度，看不出"选错了跃变"。P1 做完后，
"存在 2 个以上可比强度的候选边"应当直接压掉 `reliable`，或新增一个 `ambiguous` 标志。

## 4. 这套回归**测不到**什么 —— 还需要什么

它测的是算法对**理想化**场景的响应。下列差异仍在，任何一条都可能是现场误差的来源，
而它们**只有真实数据能回答**：

1. **真实图像质量**：反光、阴影、纹理、真正的相机模糊半径。
2. **真实点云质量**：X2 的点云在孔口/边缘处本来就有"飞点"（孔壁与底面混叠），
   我的合成点云太干净。
3. **图像与点云的真实配准误差**：这里假设两者由同一射线模型生成，完全对齐。
4. **现场实际工件的几何**：我按"台阶 1–2 mm、沉孔 0.5–2 mm"造，
   真实工件是不是这样，只有对一次真件才知道。

**所以：本结论的定位是"把嫌疑范围从 6 条缩小到 1 条"，
不是"证明现场误差就是它"。** 要坐实，需要**一个真件 + 一个已知真值**：

> **请给我一组这样的数据**：一个带台阶（或沉孔/倒角）的真实工件，
> 用卡尺或三坐标量出它的实际尺寸（尤其是图纸 Ø 对应的那个尺寸），
> 再在助手上对同一次采集跑一遍圆环拟合 / 孔径，把读数截给我。
> 有这一组，就能判定现场误差 = 缺陷 A，还是另有原因。

## 5. 要你拍板的三件事

1. **现场出问题的那类工件，是不是"边缘里面还有一道台阶/槽/沉孔"？**
   如果是，缺陷 A 就是答案，P1 直接开工；如果不是，请给我 §4 那组真件数据。
2. **P1 的"歧义时把候选都报出来"要不要做？**（会改到界面文案/输出）
   不做的话，P1 只能"改成取最外那一道" —— 对沉孔是对的，但对"最外那道其实是毛刺"
   的真件反而会错。
3. **P3（无图像时圆环拟合给 3D 粗值）要不要做？** 现在它是明确失败，
   改了就是"给一个不保证精度的数"，两种做法现场感受差别很大。
