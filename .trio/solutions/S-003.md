# S-003 解决方案：两个视窗的工具栏按钮共用同一套 UI 实现

> A 写，2026-09-30。任务书 `.trio/tasks/T-003.md`，判据 `.trio/tasks/T-003.checks.py`。

## 1. 需求复述

人：「3D 视窗和 2D 视窗的工具栏按钮**配色还是不一样**，是不是没解耦？这些按钮都属于
视窗工具栏按钮，只是分在不同视窗对应不同功能。**直接一句话：把 3D 视窗工具栏按钮的
UI 设计（不含文字和功能）跟 2D 视窗工具栏按钮做成一模一样。**」

## 2. 审查结果：为什么两边不一样（A 已定位到行）

| 侧 | 现状 | 位置 |
|---|---|---|
| 2D | 只用 `Theme::viewOverlayButtonStyle()`：常态 `background: transparent`，可见的那层“底”是 `GlassOverlay` 自己画的**背后画面模糊副本**（70% 合成） | `src/ui/Image2DView.cpp`（`GlassOverlay` 模板在 :41、`kGlassRadius` :31、`buildPageBar()` :335/:345） |
| 3D | **同一个 Theme 串 + 一段 3D 专属追加覆盖**：`QPushButton { background-color: rgba(255, 255, 255, 0.14); }` → 常态多出一层**恒定白色薄雾** | `src/ui/VisSceneView.cpp:657-659`，三处 `setStyleSheet(overlayBtnStyle)` :667/:679/:696 |

所以“配色不一样”的根因就是那行 3D 专属的白色底——**而且人猜的“没解耦”也对**：
`GlassOverlay` 现在是个**只长在 Image2DView.cpp 里的局部模板**（:41），3D 用不到，
只能自己糊一层底色。

## 3. 改法（A 给的改法，B 可以优化但必须说明）

1. 把 `GlassOverlay`（连同圆角常量）从 `Image2DView.cpp` 挪到一个**共用的头文件**
   （建议新文件 `src/ui/ViewOverlay.h`，只用头文件实现，**不要新增 .cpp**——那会牵动
   CMakeLists，超出本任务工作集）。
2. 两个视窗都用这**同一个**组件 + `Theme::viewOverlayButtonStyle()`；
   **删掉 3D 那段 `overlayBtnStyle` 追加覆盖**。
3. 模糊源是“由宿主提供”的可选项：2D 提供（`overlayBlurUnder`），3D 提供不了
   （GL 子窗口背后的像素拿不到，T-001 已证 DWM blur-behind 在本机对原生子窗口失效）。
   **没有源时组件必须什么都不画（保持透明）**，不许退化成恒定底色。

## 4. 验收场景（人能肉眼判的）

- 把 2D 与 3D 两个工具栏并排看：按钮的**圆角、常态底色、文字配色、悬停色、选中（勾选）色**
  完全一致；只有文字内容和功能不同。
- 其余照旧：程序照常启动、相机照常能连能预览。

## 5. 可执行判据

| # | 判据 | 形态 |
|---|---|---|
| 1 | 并排截图里两个工具栏按钮的 UI 一模一样 | 人判（截图） |
| 2 | 代码层：两边共用同一个浮层按钮实现 + 同一套样式；3D 里不再有专属底色覆盖；程序仍能起来 | 机检 `reports/T-003/overlay_decoupled.py` |

## 6. 风险清单（A 审查出来的，B 必须逐条守住）

1. **3D 浮层是原生窗口**：`WA_NativeWindow` + `WA_DontCreateNativeAncestors` +
   `WA_TranslucentBackground` 一个都不能丢；共用组件里**不许有任何会把祖先变原生**的调用
   （那会破坏 Vis 的嵌入，T-001 的注释里记着这条）。
2. **圆角必须只有一个来源**：QSS 的 `border-radius` 与模糊裁剪用的常量必须同值（现在都是 8）。
   拆到共享头以后，常量放头里，QSS 那边由 `Theme::viewOverlayButtonStyle()` 统一——两边必须仍然相等。
3. **不动文字、不动尺寸、不动功能**：按钮文字、顺序、位置、信号名（`onHistoryToggled` /
   `deviationColoringToggled`）、`checkable` 语义都不改。
4. **不许伤到 T-001 的成果**：`overlayBlurUnder()` 的祖先映射（`mapTo(this)` 减 `m_imageLabel->pos()`）、
   `p.setOpacity(0.70)` 只作用于模糊层、`m_p2dPage` 就是栈里那一页——这些都不能回退。
5. **不许伤到 T-002 的成果**：3D 那条提示已经不画在视窗里、改走 `logRequested` 进日志；
   那条链路别动。
6. **性能**：2D 是 30fps 实时预览，浮层重绘仍在 UI 线程；不要引入逐帧整幅模糊。
