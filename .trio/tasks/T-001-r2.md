### 3. 另一条审查意见（顺手修，说明理由）

`src/ui/VisSceneView.cpp` 里你手写的 `WindowCompositionAttributeData`：

```cpp
struct WindowCompositionAttributeData { int attribute; void* data; unsigned long dataSize; };
```

Windows 上 `unsigned long` 是 **4 字节**（LLP64），而这个 API 的 `dataSize` 是 **SIZE_T**，
x64 下 **8 字节**。结构体因此比 API 期望的少 4 字节，`dataSize` 后面那 4 字节是编译器填充
（`{}` 是否清零不保证）——调用方一次误读就可能变成天文数字。请用 `SIZE_T`
（或 `std::size_t` + 一条 static_assert 把 sizeof 钉住），并说明改了什么。
