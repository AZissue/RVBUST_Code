## 1. 背景

同一段"标定成功（使用 N 组数据）/ 4×4 矩阵（行主序）/ 逐组误差"的正文，
在两个界面页里各抄了一份：

- `src/app/MainWindow.cpp:1077` 附近（主界面「计算」）
- `src/ui/ToolsPanel.cpp:860` 附近（工具页「手眼标定」）

两处逐字相同（连 6 位小数、两个空格的分隔、`（识别失败）` 标注都一样）。
改一次措辞要改两处，而且现在已经开始分叉：只有 `ToolsPanel` 那份在成功时不动
`m_calibHint`，`MainWindow` 那份还要顺带弹 toast / 写日志。

**做完之后人能看到的**：正文一个字都不变，但它只有一个出处。

**各只出现 1 次**（现在各 2 次），且 `MainWindow.cpp` / `ToolsPanel.cpp`
都出现 `CalibrationService::formatResult(`。

判据 2 是 A 写好的验收测试（`tests/test_calibration_service.cpp`），它**引用
`CalibrationService::formatResult()`** —— 这个名字现在还不存在，所以你第一次
`cmake --build` 会因缺符号报错。那不是环境问题，是本任务要你加的接口：

```cpp
// src/logic/CalibrationService.h
// 成功 → 与现在逐字相同的那段正文；失败 → "标定失败：<error>"。
QString formatResult(const Result& r);
```

测试要求正文里必须有：`标定成功`、`N 组数据`、总平均误差（3 位小数）、`4×4 矩阵`、
矩阵首末元素（6 位小数，行主序）、`逐组误差`、`第 1 组`、逐组误差数值、
识别失败那组的 `识别失败` 标注；失败分支要含 `标定失败` 与 `r.error` 原文。
