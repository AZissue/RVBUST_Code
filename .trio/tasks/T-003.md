## 1. 背景

人反映：3D 视窗与 2D 视窗的工具栏按钮**配色仍不一致**，怀疑这两套按钮没有解耦。
要求一句话：**把 3D 视窗工具栏按钮的 UI 设计（不含文字与功能）做得与 2D 视窗的完全一样。**

A 已定位根因（见方案 §2）：2D 只用 `Theme::viewOverlayButtonStyle()`（常态透明，可见的底是
`GlassOverlay` 画的模糊副本）；3D 在同一串后面**追加了 3D 专属的白色底**
`QPushButton { background-color: rgba(255,255,255,0.14); }`（`src/ui/VisSceneView.cpp:657-659`）。
而且 `GlassOverlay` 目前只是 `Image2DView.cpp` 里的局部模板（:41），3D 用不到——**确实没解耦**。

## 2. 判据（两条）

1. **UI 一模一样（人眼判，截图）**。把程序跑起来（连相机预览、或离线冻结一张真拍 png，
   让 2D 与 3D 都有内容），并排截两个工具栏：按钮的**圆角、常态底色、文字配色、悬停色、
   勾选色**必须一致；只有文字与功能不同。
   交回时给截图：`reports/T-003/overlay2d_after.png`、`reports/T-003/overlay3d_after.png`。

2. **代码层确实解耦（机检）**：`python reports/T-003/overlay_decoupled.py` → exit 0。
   它检查：①两个视窗都调用同一个 `Theme::viewOverlayButtonStyle()`；②`VisSceneView.cpp`
   里**不再有** 3D 专属的 `background-color: rgba(...)` 覆盖；③`src/ui/` 里存在一个被
   `Image2DView.cpp` 与 `VisSceneView.cpp` **同时 include** 的头文件，且里面定义了那个浮层按钮组件；
   ④程序仍能启动并显示主窗口（冒烟）。

## 3. 明确不做

- 不改按钮文字 / 顺序 / 位置 / 尺寸 / 功能 / 信号名；不改 `checkable` 语义。
- 不动 3D 视窗自己那圈 2px 描边（人没提）。
- 不动 `logic/`、`sdk/`、`models/`、`tests/`、`src/app/`（本任务不需要动 MainWindow——
  T-002 已经接好了日志信号，别碰）。
- **不新增 .cpp**（会牵动 CMakeLists，超出工作集）；共享组件用头文件实现。
- 不动 T-001/T-002 的成果（`overlayBlurUnder` 的祖先映射、`p.setOpacity(0.70)` 只作用模糊层、
  ToolsPanel 每页恰好一个 QScrollArea、3D 提示走 `logRequested`）。
