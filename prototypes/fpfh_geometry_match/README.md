# FPFH + 几何特征匹配

1.14.3起默认支持多帧链式：勾选列表、调整顺序、首帧固定，逐帧匹配并累计到首帧；两帧模式仍保留。每对相邻帧需有足够重叠，任一步失败整批不发布；不包含闭环优化。

1.14.1起，正式入口：离线拼接窗口 → FPFH几何匹配。直接使用正式会话DB及显式保存流程，34项参数全部保留。算法/参数面板位于src，当前目录保留兼容导入及历史验证记录。

独立离线入口：运行 `prototypes/fpfh_geometry_match/run.py --session <会话目录>`。打开工业后处理窗口后点击“FPFH几何匹配”。

后处理窗口可导入PLY/PCD等点云，按实际文件单位选择mm或m；MCC内部统一毫米。点击“FPFH几何匹配”，选择参考与移动点云，计算候选，阅读诊断并确认后生成DB结果，在3D视图检查。移动帧变换到参考帧，刚体变换不拟合尺度。去平面和下采样仅用于计算，输出保留完整有效点与颜色。颜色属性不一致时拒绝合并。

参数面板支持滚动，标签和悬停提示均含用途与建议。同一后处理窗口重开保留最近计算参数；JSON导出保存全部参数及本轮诊断。原始会话不覆盖，副本结果需手动保存。

## 全部可调参数

- `voxel_mm`（默认 `5.0`）：特征体素mm：增大提速，减小保留细节；先试3/5/8。
- `normal_radius_mm`（默认 `10.0`）：法线半径mm：建议体素2倍；噪声大适当增大。
- `normal_nn`（默认 `30`）：法线最多邻点：增大更稳定但更慢。
- `feature_radius_mm`（默认 `25.0`）：FPFH半径mm：建议体素5倍；重复结构可增大。
- `feature_nn`（默认 `100`）：FPFH最多邻点：密云可增加到200。
- `backend`（默认 `exact_kdtree`）：搜索后端：exact_kdtree使用完整33维正交变换精确搜索；open3d用于对照。
- `mutual`（默认 `True`）：互近邻：减少错误对应；低重叠时可对照关闭。
- `mutual_fraction`（默认 `0.1`）：互近邻不足源特征此比例时退回单向；设0禁止回退。
- `workers`（默认 `4`）：KD树查询线程数：CPU繁忙时减小。
- `seed`（默认 `20261110`）：随机种子：固定便于复测；并行仍可能波动。
- `ransac_distance_mm`（默认 `7.5`）：RANSAC对应距离mm：建议体素1.5倍；过大容易假匹配。
- `edge_ratio`（默认 `0.9`）：边长一致比例：接近1更严格；噪声大可试0.85。
- `ransac_n`（默认 `3`）：RANSAC抽样对数：3起步；增大会显著降低采中概率。
- `ransac_iterations`（默认 `100000`）：RANSAC最大次数：低重叠可增加，耗时上升。
- `confidence`（默认 `0.999`）：RANSAC置信度：提高增加搜索时间。
- `min_consensus`（默认 `3`）：最少几何内点对：小于门禁拒绝结果；实际建议提高。
- `remove_plane`（默认 `False`）：去最大平面：背景占优时试开；仅影响求解，输出保留全云。
- `plane_voxel_mm`（默认 `2.0`）：平面计算体素mm：增大提速但损失小物体。
- `plane_threshold_mm`（默认 `3.0`）：平面距离mm：过大会删掉物体边缘。
- `plane_n`（默认 `3`）：平面抽样点数：通常3。
- `plane_iterations`（默认 `1500`）：平面RANSAC最大次数：复杂背景可增加。
- `plane_min_fraction`（默认 `0.15`）：平面最小占比：低于此值拒绝去平面。
- `plane_max_fraction`（默认 `0.95`）：平面最大占比：高于此值视为剩余几何不足。
- `plane_min_remaining`（默认 `2048`）：去平面最少剩余点：小目标可调低并人工核对。
- `icp`（默认 `False`）：启用点到点ICP：先验证粗配准，再开启。
- `icp_voxel_mm`（默认 `2.0`）：ICP计算体素mm：减小提高细节但变慢。
- `icp_distance_mm`（默认 `10.0`）：ICP距离mm：过大可能吸附错误平面。
- `icp_iterations`（默认 `50`）：ICP最大迭代：30至100起步。
- `icp_relative_fitness`（默认 `1e-06`）：ICP适应度停止变化量：减小更严格。
- `icp_relative_rmse`（默认 `1e-06`）：ICP残差停止变化量：减小更严格。
- `eval_voxel_mm`（默认 `2.0`）：评估体素mm：对照实验保持一致。
- `eval_max_points`（默认 `50000`）：每侧评估采样上限：固定种子可复测。
- `eval_distance_mm`（默认 `10.0`）：评估内点距离mm：不能用放宽阈值证明精度改善。
- `min_fscore`（默认 `0.0`）：双向覆盖F值门禁：0仅检查共识；实际按场景提高。

## 调试顺序

1. 确认单位，先关闭去平面和ICP，以5mm体素、10mm法线半径、25mm特征半径起步。
2. 体素试3/5/8mm时同步调整法线、特征与RANSAC距离。每轮只改一组参数并导出报告。
3. 背景平面主导时开启去平面；失败提示剩余几何不足时先关闭，或裁剪物体后再试。不能只靠放宽平面门禁获得可信结果。
4. 粗配准合理后开启ICP。固定评估体素、采样上限、随机种子与距离比较粗/精结果。残差下降可能伴随覆盖下降，应同时检查双向覆盖。
5. 对称、重复结构和低重叠可产生错误多解。默认最少共识3仅是数学下限；实际提高最少共识及F值门禁，并在3D视图检查。不宣称自动消除歧义。

FPFH描述子固定为Open3D 33维定义；点到点刚体估计不允许尺度变化。精确KD树后端保留完整维度、不白化，eps固定0。算法类型和数学定义不是可调超参数。未做跨次特征缓存，避免输入/参数变化后复用旧结果。长任务后台执行，完成前关闭门禁生效，暂无中途取消。
