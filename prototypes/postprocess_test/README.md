# 后处理测试工具

独立原型，用于测试点云后处理功能与 3D 点云显示控件。

## 运行

```bash
python prototypes/postprocess_test/app.py
```

## 界面布局

- **左侧 DB 树**：参考 CloudCompare 风格，按文件层级展示点云对象；
  每个节点带复选框，可控制是否显示在 3D 视图中。
- **中间 3D 视图**：复用 `src/ui/viewer_3d.py` 的 `EmbeddedPointCloudViewer`，
  支持叠加显示多路点云、视角切换、点大小调整、坐标轴/网格等。
- **右侧后处理面板**：提供体素下采样、统计离群点去除、AABB/球/OBB 裁切；
  可应用到当前选中的点云对象，并保存处理结果。

## 使用流程

1. 点击「打开点云文件」或「打开点云文件夹」加载 PLY/PCD/XYZ 文件；
2. 在 DB 树中勾选需要显示的点云对象；
3. 选中某个点云对象后，在右侧面板调整后处理参数；
4. 点击「应用到当前选中」查看处理效果；
5. 点击「保存当前点云」导出处理后的结果。

## 注意

- 本工具不依赖 RVC SDK，仅需 open3d + PySide6；
- 后处理参数为原型默认值，正式接入主程序时可进一步调优。
