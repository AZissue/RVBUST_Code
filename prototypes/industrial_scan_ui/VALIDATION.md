## 独立包验证

Windows x64 PyInstaller 目录包已构建。发现打包工具会从开发机 PATH 的其他工具中误收集同名 `icuuc.dll`，覆盖 Qt 所需的 Windows 系统 ICU API，导致干净环境 QtCore 加载失败。已在 spec 中排除这个冲突 DLL，不复制或修改系统 DLL。

验证子进程移除 Conda、Python、Qt 开发环境变量，PATH 仅保留 Windows System32；EXE 的临时 PLY 读写自检及原生 OpenGL 窗口截图均退出码 0，截图已查看。此验证说明运行包不依赖开发环境 PATH；它仍在同一 Windows 系统上运行，不能替代客户干净机器验收。构建产物保存在工作目录外的 `.verify_reports/industrial-scan-dist/`，不上传 Git。
