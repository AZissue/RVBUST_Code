# 普通圆点识别与三角形几何匹配原型

本原型处理**普通无编码实心黑/白圆点及黑环浅灰心标记**。算法从图像识别圆心，在对应的有序点云中提取三维坐标。UI 复用主程序的实验副本、图像预览、后台任务、DB 结果、撤销和会话。

## 入口与试用

1. 在MCC主工作区导入或采集至少两帧原始数据，保留同帧的原始2D图像与逐像素有序点云。单位为mm；点数必须等于图像宽×高。文件点序是否真实对应图像仍需操作者保证，裁剪、下采样或重排后的PLY不能使用。
2. 运行 `prototypes/circle_geometry_match/run.py --session <会话目录>`，在工业后处理窗口顶部点击“圆点匹配”。
3. 选择固定参考帧和移动帧；设置黑/白圆点、图像阈值（默认Otsu）、圆半径像素范围与圆度。两个输入必须是原始DB帧，不能选拼接结果。可在副本主窗口按现有方式打开保存会话，然后重开后处理。
4. 点击“识别圆点并计算三角匹配”。绿色为已配对有效3D圆心，黄色为有深度但未配对圆心，红色为无有效深度的2D圆点。两侧相同编号为对应关系，黄色虚线标出一组三角形。
5. 查看有效圆点数、对应数、圆心RMS/最大误差和移动→参考矩阵，人工核对编号是否对应同一物理圆点并确认mm单位，才可生成拼接结果。
6. 新增独立DB结果，保留两帧全部有效点和原始颜色，以及来源和最终位姿；原始帧不改动。支持撤销、PLY导出及显式保存验证会话到 `outputs/experiments/`。

## 匹配规则

- 先根据二维封闭外轮廓、面积、圆度和椭圆轴比筛选候选。对圆环检查内外轮廓的同心性和形状，每个标记以外轮廓拟合的中心计一次。黑环灰心靶标选择「黑圆点 / 浅色背景」，可先用自动 Otsu，成像后需能分辨黑环与灰心。
- 拒绝边界截断的标记。从圆心附近的有序 3D 邻域取有效深度中位数，深度断层或不足 3 个有效样本时仅显示 2D 诊断。
- 每帧最多24个圆点候选；不静默截断。每帧至少3个有效3D圆心；建议布置4个以上不对称圆点，提高遮挡和干扰下的可判别性。
- 在三维坐标中枚举非退化三角形，以排序边长检索候选，再枚举顶点对应。边长容差=绝对容差+最长边×相对容差，默认1mm+1%；默认最短边5mm，这些参数可调整。
- 只求旋转和平移，不拟合尺度，不使用2D边长直接拼接。采用全体有效圆心的一对一一致性评分，并用对应点细化刚体变换；圆心对应距离默认2mm。
- 优先匹配数更多、残差更小的解。存在同等可信的不同对应关系时拒绝。等边、等腰三角形、规则重复图案或只有共线点时可能无法唯一确定方向，不能凭低RMS认定成功。候选验证超过5000次时失败并提示收紧范围，不以未检查完的结果放行。
- 不自动执行ICP，也不启动相机SDK。圆心残差不是整幅点云表面精度，真机场景效果需要独立验收。普通圆点不具备物体身份编码，人工核对仍是必要步骤。

## 后续多边形扩展

`core/matching.py` 提供 `match_geometry(reference_centres, moving_centres, parameters, shape)` 和 `MATCHERS` 注册表；目前只注册 `triangle`。匹配器返回 `transform`（moving→reference）、`pairs`（参考/移动索引）、`rms`、`errors` 与 `shape`，三角策略另返回用于显示的 `triangle_pairs`。后续可在相同圆心观测与DB发布接口下增加多边形候选策略。当前未知shape会明确报错，不以三角形冒充多边形实现。
