# 离线测试数据

`stool/` 保存凳子采集第 1、2 帧，供新版三个工作区和工业 UI 原型共用。
每个 ZIP 内包含原始同名 PLY 和 PNG；无损压缩，不下采样、不重排点序，
保留图像像素与有序点云的对应关系。manifest 记录毫米单位、文件 SHA-256
及真实编码圆检测结果。运行时校验并展开到忽略提交的 `.cache/`。

- 多相机：1、2 帧作为两个视角输入，用于检测、外参计算测试；并非同步双机采集。
- 移动链式拼接：作为两个机位，自动调用正式离线配准；工作副本在
  `offline_data/preview_sessions/`，删除机位不会删除本目录的数据。
  自带数据预览显式回放 manifest 中的识别记录，避免重复检测带来结果变化；
  配准质量仍须满足正式门槛。普通离线目录未提供识别记录时每帧检测一次。
- 转台：作为 frame0 / frame1，供预览和标定算法测试；拍摄没有已知转台角度，
  不能作为转台精度或完整 360° 重建验收数据。

原始 PLY 始终保留全部点；预览排除非有限值和零坐标占位点，并继续使用
查看器的交互显示采样。离线链式预览关闭统计离群过滤和体素下采样，
仅排除无效占位点；不改变在线采集的处理参数。

在启动小窗选择任一「新版」功能，点击「离线预览 · 凳子数据」。
无须添加测试设备；不初始化、枚举或连接实体相机。需要在线采集时，
点击刷新设备，再使用「连接并进入」。主窗口设备管理可切换其他离线工作区。
原型的「离线预览」入口也会自动加载同一数据。

重新生成数据包：`python tools/prepare_offline_fixture.py <原始采集目录>`。
该操作需要目录中的 `1.ply / 1.png / 2.ply / 2.png`。
